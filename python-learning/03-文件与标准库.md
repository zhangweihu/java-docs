## 3.1 pathlib：现代化的路径操作（Python 3.4+，官方推荐）

第一章已简单用过，这里**全面掌握**。`pathlib` 把路径当"对象"处理（对应 Java 的 `java.nio.file.Path`），**彻底取代 `os.path` 字符串拼接**。

### 3.1.1 Path 的核心属性

```python
from pathlib import Path

p = Path("data/reports/2026-08.txt")

print(p.name)            # 2026-08.txt   文件名
print(p.stem)            # 2026-08       去后缀的文件名
print(p.suffix)          # .txt          后缀（含点）
print(p.suffixes)        # ['.txt']      多个后缀列表
print(p.parent)          # data/reports  父目录（Path 对象）
print(p.parents)         # [data/reports, data, .]  所有祖先（近到远）
print(p.root)            # 空（Windows 上是 \）
print(p.anchor)          # 空（Windows 上是盘符 C:\）
print(p.exists())        # False  是否存在
print(p.is_file(), p.is_dir())   # False False
```

### 3.1.2 路径拼接与规范化（告别字符串 +

```python
base = Path("data")
# 拼接（/ 运算符！比 os.path.join 优雅）
sub = base / "reports" / "2026"      # data/reports/2026
full = base.joinpath("a", "b", "c")  # data/a/b/c
print(full)

# 规范化
print(Path("data/./a/../b").resolve())   # 绝对路径 + 解析 . 和 ..（真实路径）
print(Path("data/a.txt").absolute())     # 转绝对路径（不解析软链）

# 相对路径计算
print(Path("a/x.txt").relative_to("a"))  # x.txt
# 类型互转
str(Path("data/a.txt"))                  # 'data/a.txt'（传给别人/数据库时转 str）
Path("data/a.txt") == Path("data", "a.txt")  # True（等值比较，不拼字符串）
```

### 3.1.3 目录操作与 glob 通配

```python
from pathlib import Path

# 创建目录（exist_ok 幂等，parents 递归建父目录）
Path("logs/2026/08").mkdir(parents=True, exist_ok=True)

# 列出目录内容
for entry in Path(".").iterdir():        # 直接子项
    print(entry.name, "目录" if entry.is_dir() else "文件")

# glob 通配（递归 **，对应 shell 的 find 模式）
for py in Path(".").glob("*.py"):        # 当前目录所有 .py
    print(py)
for md in Path(".").rglob("*.md"):       # 递归所有子目录的 .md（rglob = 递归 glob）
    print(md)

# 单文件通配
m = Path("data").glob("2026-*.txt")
print(list(m))
```

### 3.1.4 文件读写、复制、删除（Path 一站式）

```python
from pathlib import Path

p = Path("note.txt")

# 读写（自动管理编码，比 open 简洁；文件不存在时 read 抛 FileNotFoundError）
p.write_text("第一行\n第二行", encoding="utf-8")
content = p.read_text(encoding="utf-8")
print(content)

# 二进制读写
p.write_bytes(b"\x00\x01\x02")
data = p.read_bytes()

# 追加（注意：Path 没有 append，需要 open）
with p.open("a", encoding="utf-8") as f:
    f.write("追加内容\n")

# 复制与删除（Path 本身无 copy 方法，用 shutil）
import shutil
shutil.copy("note.txt", "note_backup.txt")
shutil.move("note_backup.txt", "backup/note.txt")   # 移动/改名
Path("note.txt").unlink(missing_ok=True)            # 删除文件（不存在也不报错）
shutil.rmtree("backup", ignore_errors=True)         # 递归删除目录

# 文件信息
st = Path("note.txt").stat()
print(st.st_size)              # 字节数
```

> **经验**：路径全部用 `Path` 对象；跨 Windows/Linux 自动处理分隔符；与第三方库（pandas、open）对接时用 `str(p)` 或直接传 Path（现代库都支持）。

## 3.2 文本与编码：utf-8 的前世今生

### 3.2.1 编码基础（面试常问）

| 概念 | 说明 |
| --- | --- |
| ASCII | 128 个字符（英文字母/数字/符号），1 字节 |
| UTF-8 | 变长编码（1~4 字节），**兼容 ASCII**，互联网与 Python 默认 |
| UTF-16/UTF-32 | 定长/变长，Windows 内部常用 |
| GBK/GB2312 | 中文编码（国内老系统遗留），与 UTF-8 不兼容 |

```python
s = "中文Python"
b = s.encode("utf-8")        # 编码：str → bytes
print(b)                     # b'\xe4\xb8\xad\xe6\x96\x87Python'
print(b.decode("utf-8"))     # 解码：bytes → str，还原中文Python

# 乱码根源：用错编码读写
# b.decode("gbk")   ❌ UnicodeDecodeError 或乱码
```

> **黄金法则**：所有文件读写统一 `encoding="utf-8"`；读老系统导出的 GBK 文件才用 `encoding="gbk"`；拿不准可 `encoding="utf-8", errors="replace"` 容错。

### 3.2.2 BOM 陷阱（Windows 用户高频踩坑）

```python
# Excel 另存为 CSV 时默认带 BOM（\ufeff），读出来首列多一个看不见的字符
text = "\ufeff姓名,分数"
print(text[0])                     # 看不见的 \ufeff
# 处理方式：
from pathlib import Path
import codecs
# 方式1：utf-8-sig 自动吃掉 BOM
content = Path("data.csv").read_text(encoding="utf-8-sig")
# 方式2：写的时候用 utf-8-sig 让 Excel 能正确识别中文（Windows 场景）
Path("out.csv").write_text("姓名,分数\n", encoding="utf-8-sig")
```

### 3.2.3 大文件流式处理（不占内存）

```python
from pathlib import Path

# 逐行读：处理几 GB 日志的标配
def count_lines(path: str) -> int:
    count = 0
    with Path(path).open("r", encoding="utf-8") as f:
        for _ in f:                # 文件对象可迭代，一次一行（内部缓冲）
            count += 1
    return count

# 按固定字节块读（二进制大文件）
def read_in_chunks(path: str, chunk_size: int = 1024 * 1024):
    with Path(path).open("rb") as f:
        while chunk := f.read(chunk_size):      # 海象运算符 :=
            yield chunk

# 超长行注意：readline 可能撑爆内存，用 read(size) 限长
```

## 3.3 CSV 处理（csv 标准库）

对应 Java 的 `OpenCSV`/`Apache Commons CSV`。**凡是表格数据，优先考虑 CSV 而非 Excel**（通用、轻量、Git 友好）。

### 3.3.1 基础读写

```python
import csv

# 写入（newline="" 是 Windows 防多空行的关键！）
with open("students.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["name", "score"])           # 表头
    writer.writerows([["Tom", 92], ["Amy", 88]]) # 多行

# 读取
with open("students.csv", "r", encoding="utf-8") as f:
    reader = csv.reader(f)
    for row in reader:                           # row 是列表
        print(row)                               # ['name', 'score'] / ['Tom', '92']
```

### 3.3.2 DictReader / DictWriter（推荐，按列名操作）

```python
import csv

# 写入：字典按 fieldnames 顺序落列
with open("students.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["name", "score", "city"])
    writer.writeheader()                         # 写表头
    writer.writerow({"name": "Tom", "score": 92, "city": "北京"})
    writer.writerows([
        {"name": "Amy", "score": 88, "city": "上海"},
        {"name": "Bob", "score": 75, "city": "广州"},
    ])

# 读取：返回 OrderedDict，按列名访问（可读性最好）
with open("students.csv", "r", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        print(row["name"], row["score"], row["city"])
```

### 3.3.3 大 CSV 分块处理 + 异常行容错

```python
import csv

def process_big_csv(path: str, chunk: int = 1000):
    """按块处理大 CSV（内存友好），坏行跳过不中断"""
    batch = []
    with open(path, "r", encoding="utf-8") as f:
        reader = csv.DictReader(f)
        for i, row in enumerate(reader, start=1):
            try:
                batch.append({"name": row["name"], "score": float(row["score"])})
            except (ValueError, KeyError) as e:
                print(f"第 {i} 行跳过：{e}")
                continue
            if len(batch) >= chunk:
                yield batch                     # 交出去处理一批
                batch = []
    if batch:
        yield batch

for batch in process_big_csv("students.csv"):
    print("处理一批", len(batch), "行")
```

> 面试题：**CSV 里的字段本身含逗号/引号/换行怎么办？** csv 模块自动处理（字段含逗号自动加引号包裹，含引号自动转义为两个引号），`reader` 读回来是完整字段。所以"用 `split(",")` 解析 CSV"是反模式。

## 3.4 JSON 深入（对应 Java Jackson/Gson）

### 3.4.1 基础用法与常用参数

```python
import json

data = {
    "name": "Tom",
    "age": 25,
    "tags": ["a", "b"],
    "active": True,
    "nothing": None,
}

# 序列化 str
text = json.dumps(data, ensure_ascii=False, indent=2)
print(text)
# {
#   "name": "Tom", ...
# }

# 反序列化
back = json.loads(text)
print(back["name"], type(back["tags"]))

# 文件级读写（高频）
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
with open("data.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)
```

| 参数 | 作用 | 默认 |
| --- | --- | --- |
| `ensure_ascii=False` | 中文不转 `\uXXXX`（否则全变乱码样） | True |
| `indent=2` | 格式化输出（配置文件/调试用） | None（单行） |
| `sort_keys=True` | 键排序（输出稳定，利于 diff） | False |
| `default=str` | 序列化不了的对象兜底转字符串 | 抛 TypeError |
| `separators=(",", ":")` | 压缩输出（省体积） | 默认带空格 |

### 3.4.2 自定义对象序列化（对应 Jackson 的 @JsonProperty/@JsonFormat）

```python
import json
from dataclasses import dataclass, asdict
from datetime import datetime

# 方式1：dataclasses.asdict 快速转字典（配合 dataclass，最省事）
@dataclass
class User:
    name: str
    created: str

u = User("Tom", "2026-08-19")
print(json.dumps(asdict(u), ensure_ascii=False))     # {"name": "Tom", "created": "2026-08-19"}

# 方式2：default 回调兜底未知类型
def default(obj):
    if isinstance(obj, datetime):
        return obj.strftime("%Y-%m-%d %H:%M:%S")
    raise TypeError(f"无法序列化 {type(obj)}")

now = {"time": datetime.now()}
print(json.dumps(now, default=default))
```

### 3.4.3 JSONL 与超大 JSON

```python
import json

# JSONL：一行一个 JSON 对象（日志、数据管道标准格式，可追加可断点续读）
def write_jsonl(path, records):
    with open(path, "a", encoding="utf-8") as f:
        for r in records:
            f.write(json.dumps(r, ensure_ascii=False) + "\n")

def read_jsonl(path):
    with open(path, "r", encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                yield json.loads(line)
```

## 3.6 日志 logging（对应 Java 的 SLF4J + logback）

日志是生产排查的第一工具，**永远不要用 print 打日志**。logging 是标准库，无需安装。

### 3.6.1 五分钟上手

```python
import logging

# 基本配置（开发期够用）
logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)s [%(name)s] %(message)s",
    datefmt="%Y-%m-%d %H:%M:%S",
)

# 各模块拿自己的 logger（对应 Java LoggerFactory.getLogger(Xxx.class)）
logger = logging.getLogger(__name__)

logger.debug("调试信息（默认不显示）")
logger.info("用户 %s 登录成功", "Tom")          # 惰性拼接，传参不要用 f-string
logger.warning("磁盘空间不足 %d%%", 85)
logger.error("数据库连接失败", exc_info=True)   # exc_info=True 打印堆栈
```

级别：`DEBUG < INFO < WARNING < ERROR < CRITICAL`。`basicConfig(level=...)` 控制最低输出级别。

### 3.6.2 核心概念：Logger / Handler / Formatter（对应 logback 的 appender）

```
Logger（记录器：谁在打日志）——> Handler（处理器：输出到哪）
                              ├── StreamHandler：控制台
                              ├── FileHandler：文件
                              └── RotatingFileHandler：按大小轮转
        Formatter（格式器：怎么排版）
```

```python
import logging
from logging.handlers import RotatingFileHandler

logger = logging.getLogger("app")

# 格式器
fmt = logging.Formatter("%(asctime)s %(levelname)s %(name)s:%(lineno)d - %(message)s")

# 控制台
console = logging.StreamHandler()
console.setFormatter(fmt)
# 文件（按 5MB 轮转，保留 3 个备份）
file_h = RotatingFileHandler("app.log", maxBytes=5 * 1024 * 1024, backupCount=3, encoding="utf-8")
file_h.setFormatter(fmt)

logger.addHandler(console)
logger.addHandler(file_h)
logger.setLevel(logging.INFO)

logger.info("应用启动")            # 同时进控制台和文件
```

> 注意：logger 是**层级命名**的（`a.b` 的父是 `a`），**每个模块用 `logging.getLogger(__name__)`** 即可自动分级；Handler 不要重复 add（会重复输出）。

### 3.6.3 dictConfig：生产级配置（对应 logback.xml）

```python
import logging.config

LOGGING_CONFIG = {
    "version": 1,
    "disable_existing_loggers": False,
    "formatters": {
        "standard": {"format": "%(asctime)s %(levelname)s [%(name)s] %(message)s"},
        "detail": {"format": "%(asctime)s %(levelname)s %(name)s:%(lineno)d %(message)s"},
    },
    "handlers": {
        "console": {"class": "logging.StreamHandler", "formatter": "standard", "level": "INFO"},
        "file": {
            "class": "logging.handlers.RotatingFileHandler",
            "filename": "logs/app.log",
            "maxBytes": 10485760,          # 10MB
            "backupCount": 5,
            "encoding": "utf-8",
            "formatter": "detail",
            "level": "DEBUG",
        },
    },
    "root": {"handlers": ["console", "file"], "level": "INFO"},
    "loggers": {
        "fastapi": {"level": "WARNING"},   # 第三方库降噪
        "sqlalchemy": {"level": "WARNING"},
    },
}

logging.config.dictConfig(LOGGING_CONFIG)
logger = logging.getLogger("app")
logger.info("服务启动完成")
```

> **实践规范**：生产日志输出到文件（按大小/时间轮转）+ 控制台；第三方库（requests/fastapi）级别调到 WARNING 降噪；敏感信息（密码/token）**禁止打日志**。

## 3.9 其他高频标准库（一次认识）

```python

# uuid：通用唯一标识（对应 Java UUID.randomUUID()）

shutil.move("b.txt", "dir/")                 # 移动
shutil.disk_usage(".")                       # 磁盘空间
```

### 面试高频问题清单

| 问题 | 答案要点 |
| --- | --- |
| pathlib 相比 os.path 优点？ | 面向对象、跨平台、`/` 拼接、glob、自带读写；官方推荐 |
| 为什么文件读写用 with open？ | 自动关闭；异常也安全；`__enter__/__exit__` 上下文管理 |
| 编码乱码怎么排查？ | 确认源文件编码；统一 utf-8；BOM 用 utf-8-sig；错误内容别二次写入 |
| 大文件怎么处理？ | 逐行迭代/按块 read(size)；别 read() 全量；生成器惰性处理 |
| JSON 序列化 datetime/自定义对象？ | default 回调 / dataclasses.asdict / 自定义 encoder |
| JSON 与 JSONL 区别？ | JSON 单对象；JSONL 一行一对象，可追加、可流式、断点续读 |
| CSV 字段含逗号怎么办？ | csv 模块自动加引号处理；不要用 split(",") |
| logging 为什么不用 print？ | 分级、格式、输出到文件/轮转、生产可开关；print 不可控 |
| logging 核心三件？ | Logger（谁打）、Handler（打到哪）、Formatter（怎么排）；dictConfig 对应 logback.xml |
| RotatingFileHandler？ | 按大小轮转 + backupCount 备份，避免单文件无限膨胀 |
| 密码怎么存？ | 哈希 + 盐（bcrypt/argon2 最佳）；**绝不存明文、不存裸 md5/sha** |
| 配置怎么管？ | .env 本地差异 + 环境变量生产；敏感信息不进代码库 |
| uuid 与 secrets 区别？ | uuid 唯一标识；secrets 密码学安全随机（token/密钥） |
