# 第七章 数据分析：NumPy、Pandas 与 Matplotlib

> 本章目标：掌握 Python 数据分析三件套——**NumPy**（数值计算，对标 Java 的数组/Stream 数值流）、**Pandas**（表格处理，对标 Java 的集合 + Excel 操作 + SQL 能力）、**Matplotlib**（可视化）。学完能独立完成"读数据 → 清洗 → 分析 → 出图"的完整数据分析流程，这是 Python 相对 Java 的**最大优势场景**，也是数据/AI 方向的必备技能。
>
> 前置知识：第一章~第三章（语法、文件读写）。建议对照 java-learning 的集合/Stream 章节与 Excel 处理经验理解。
>
> 环境准备：`pip install numpy pandas matplotlib`（数据分析三件套，一次装齐）。

## 7.1 为什么数据分析是 Python 的"主场"

| 对比 | Python（Pandas） | Java |
| --- | --- | --- |
| 表格数据操作 | DataFrame 一行代码筛选/分组/聚合 | 要写一堆 for + 集合操作 + DTO |
| 缺失值处理 | `dropna()` / `fillna()` 一行 | 手写 null 判断循环 |
| 数值计算 | 向量化（底层 C）秒级 | 循环逐元素，慢且啰嗦 |
| 可视化 | Matplotlib 三行出图 | 需要引入第三方图表库 |
| 生态衔接 | 直接对接机器学习库（sklearn） | 需要额外框架 |

**核心思想：向量化操作。** 别用 for 循环逐行处理，而是用"对整列/整表操作"的方式——底层是 C 实现，**比 Python 循环快几十到几百倍**。

## 7.2 NumPy：高性能数值计算

NumPy 提供 **ndarray（N 维数组）**——比 Python 内置 list 快、省内存、支持向量化运算。

### 7.2.1 创建数组

```python
import numpy as np

# 从列表创建
a = np.array([1, 2, 3, 4, 5])
print(a, a.shape)              # [1 2 3 4 5] (5,)        一维

# 二维数组（矩阵）
m = np.array([[1, 2, 3], [4, 5, 6]])
print(m.shape)                 # (2, 3)    2 行 3 列

# 常用创建函数
np.zeros((2, 3))               # 全 0 矩阵
np.ones(5)                     # 全 1
np.full(4, 7)                  # [7 7 7 7]
np.arange(0, 10, 2)            # [0 2 4 6 8]    类似 range
np.linspace(0, 1, 5)           # [0. 0.25 0.5 0.75 1.]  等差数列
np.random.randint(0, 100, 10)  # 10 个 0~99 随机整数
np.random.randn(1000)          # 1000 个标准正态分布随机数
```

### 7.2.2 向量化运算（告别 for 循环）

```python
import numpy as np

a = np.array([1, 2, 3, 4, 5])
b = np.array([10, 20, 30, 40, 50])

print(a + b)        # [11 22 33 44 55]    逐元素加
print(a * 2)        # [ 2  4  6  8 10]    广播：标量自动扩展到每个元素
print(a ** 2)       # [ 1  4  9 16 25]
print(a > 2)        # [False False  True  True  True]  逐元素比较（布尔数组）

# 聚合运算（对标 Java Stream 的 reduce）
print(a.sum())          # 15
print(a.mean())         # 3.0
print(a.max(), a.min()) # 5 1
print(a.std())          # 1.414...  标准差
print(np.median(a))     # 3.0
```

**广播（Broadcasting）**：不同形状数组自动扩展匹配，是向量化的灵魂：

```python
m = np.array([[1, 2], [3, 4], [5, 6]])     # (3, 2)
row = np.array([10, 20])                    # (2,) → 广播成 (3, 2)
print(m + row)
# [[11 22]
#  [13 24]
#  [15 26]]
```

### 7.2.3 索引、切片与条件筛选

```python
import numpy as np

a = np.array([10, 20, 30, 40, 50])
print(a[1])            # 20
print(a[1:4])          # [20 30 40]    切片（和 list 一样）
print(a[::-1])         # [50 40 30 20 10]  反转

# 布尔索引（数据筛选的核心，对标 SQL 的 WHERE）
print(a[a > 30])       # [40 50]
print(a[(a > 20) & (a < 50)])   # [30 40]   注意 & 不是 and

m = np.array([[1, 2, 3], [4, 5, 6]])
print(m[0, 1])         # 2    第 0 行第 1 列
print(m[:, 1])         # [2 5]  所有行的第 1 列（冒号 = 整维）
print(m[1, :])         # [4 5 6]  第 1 行
```

## 7.3 Pandas 核心：Series 与 DataFrame

Pandas 建立在 NumPy 之上，核心是 **Series**（一列）和 **DataFrame**（表格，对标数据库表 / Excel 表 / Java 的 List<Map>）。

### 7.3.1 创建与基本认识

```python
import pandas as pd

# Series：一列带索引的数据
s = pd.Series([10, 20, 30], index=["a", "b", "c"])
print(s)
# a    10
# b    20
# c    30
print(s["b"])          # 20   按索引取值（类似 dict）

# DataFrame：表格（字典的键 = 列名）
df = pd.DataFrame({
    "姓名": ["张三", "李四", "王五", "赵六"],
    "部门": ["技术", "市场", "技术", "财务"],
    "工资": [15000, 12000, 18000, 10000],
    "入职年份": [2020, 2021, 2019, 2022],
})
print(df)
```

### 7.3.2 数据读取：一行接住各种来源（对标数据导入）

## 7.4 数据清洗（分析工作中 80% 的时间都在这里）

### 7.4.1 缺失值处理（对标 SQL 的 IS NULL 处理）

```python
import pandas as pd

df = pd.DataFrame({
    "姓名": ["张三", "李四", "王五"],
    "工资": [15000, None, 18000],
    "评分": [4.5, 3.8, None],
})

# 1. 发现缺失
print(df.isnull())                    # 逐格布尔矩阵
print(df.isnull().sum())              # 每列缺失个数

# 2. 删除含缺失值的行（丢弃法：数据量大、缺失少时用）
df_drop = df.dropna()

# 3. 填充（填充法：保留数据）
df_fill = df.fillna(0)                           # 填 0
df_fill2 = df["工资"].fillna(df["工资"].mean())   # 数值列填均值（常用）
df_fill3 = df["评分"].fillna(method="ffill")     # 用上一行填充（时间序列常用）
```

### 7.4.2 重复与异常值处理

```python
# 重复行
print(df.duplicated().sum())          # 重复行数
df = df.drop_duplicates()             # 去重（可按 subset 指定列）
df = df.drop_duplicates(subset=["姓名"], keep="first")

# 异常值：用描述统计定位（如工资 > 3 倍标准差视为异常）
mean, std = df["工资"].mean(), df["工资"].std()
abnormal = df[df["工资"] > mean + 3 * std]
```

### 7.4.3 类型转换与新增列

```python
# 类型转换（读 CSV 时常遇到：数字被识别成字符串）
df["工资"] = pd.to_numeric(df["工资"], errors="coerce")   # 转数值，失败变 NaN

# 日期解析
df["入职日期"] = pd.to_datetime(df["入职年份"].astype(str) + "-01-01")

# 新增列（对标 SQL 的 SELECT 计算列）
df["年薪"] = df["工资"] * 12
df["级别"] = df["工资"].apply(lambda x: "高" if x >= 15000 else "中低")

# 条件赋值（对标 SQL CASE WHEN）
df["等级"] = pd.cut(df["工资"], bins=[0, 12000, 18000, 99999],
                    labels=["C", "B", "A"])
print(df["等级"].value_counts())      # 每个等级的人数
```

## 7.5 筛选、排序与分组聚合（对标 SQL）

### 7.5.1 筛选与排序（对标 WHERE / ORDER BY）

```python
import pandas as pd

df = pd.DataFrame({
    "姓名": ["张三", "李四", "王五", "赵六", "孙七"],
    "部门": ["技术", "市场", "技术", "财务", "技术"],
    "工资": [15000, 12000, 18000, 10000, 20000],
    "入职年份": [2020, 2021, 2019, 2022, 2020],
})

# 条件筛选（对标 WHERE）——注意 & | 而不是 and or
tech = df[df["部门"] == "技术"]
high = df[(df["工资"] > 12000) & (df["部门"] == "技术")]
print(high[["姓名", "工资"]])               # 只选列（对标 SELECT 列）

# 排序（对标 ORDER BY）
df.sort_values("工资", ascending=False)     # 工资降序
df.sort_values(["部门", "工资"], ascending=[True, False])   # 多列排序

# 取一列
print(df["工资"].max())                     # 20000
print(df["工资"].mean())                    # 15000.0
```

### 7.5.2 分组聚合（对标 GROUP BY + 聚合函数）

```python
# 按部门分组，算工资均值/总和/人数
print(df.groupby("部门")["工资"].mean())
# 部门
# 财务    10000.0
# 市场    12000.0
# 技术    17666.7

# 多聚合函数同时算
print(df.groupby("部门")["工资"].agg(["count", "mean", "max", "min"]))

# 按多列分组
print(df.groupby(["部门", "入职年份"])["工资"].sum())

# 聚合后 reset_index 变回普通表格（便于后续操作）
summary = df.groupby("部门")["工资"].mean().reset_index()
```

### 7.5.3 merge 与 concat（对标 SQL JOIN / UNION）

```python
# merge：按列关联（对标 JOIN）
df_employee = pd.DataFrame({"姓名": ["张三", "李四"], "部门": ["技术", "市场"]})
df_salary = pd.DataFrame({"姓名": ["张三", "李四"], "工资": [15000, 12000]})
merged = pd.merge(df_employee, df_salary, on="姓名", how="inner")
# how 可选：inner 内连接 / left 左连接 / outer 全外连接

# concat：行拼接（对标 UNION）
df1 = pd.DataFrame({"姓名": ["张三"]})
df2 = pd.DataFrame({"姓名": ["李四"]})
union = pd.concat([df1, df2], ignore_index=True)
```

### 7.5.4 数据透视表（对标 Excel 透视表 / GROUP BY 多维版）

```python
# 行 = 部门，列 = 入职年份，值 = 工资均值
pivot = df.pivot_table(index="部门", columns="入职年份", values="工资",
                       aggfunc="mean", fill_value=0)
print(pivot)
```

## 7.7 实战：销售数据分析报告（综合实战）

目标：读取销售 CSV → 清洗 → 分析 → 出图 → 输出报告。串联全章知识。

```python
"""销售数据分析：读取 → 清洗 → 分析 → 可视化 → 报告导出"""
import pandas as pd
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["Microsoft YaHei"]
plt.rcParams["axes.unicode_minus"] = False

# ─── 1. 读取（模拟数据，实际可替换成 read_excel/read_sql）───
df = pd.DataFrame({
    "订单号": [f"SO{i:04d}" for i in range(1, 101)],
    "品类": np.random.choice(["手机", "电脑", "耳机", "手表"], 100),
    "金额": np.random.randint(500, 10000, 100).astype(float),
    "城市": np.random.choice(["北京", "上海", "广州", "深圳"], 100),
    "日期": pd.date_range("2026-01-01", periods=100),
})
df.loc[5, "金额"] = None          # 造一个缺失值

# ─── 2. 清洗 ───
print("清洗前缺失数:", df["金额"].isnull().sum())
df["金额"] = df["金额"].fillna(df["金额"].mean())     # 缺失金额填均值
df = df.drop_duplicates()                             # 去重

# ─── 3. 分析 ───
# 各品类销售额与销量
cat_summary = df.groupby("品类")["金额"].agg(["sum", "count", "mean"]).reset_index()
cat_summary = cat_summary.rename(columns={"sum": "销售额", "count": "销量", "mean": "客单价"})
print("=== 品类分析 ===")
print(cat_summary.sort_values("销售额", ascending=False))

# 各城市销售额
city_summary = df.groupby("城市")["金额"].sum().sort_values(ascending=False)
print("=== 城市分析 ===")
print(city_summary)

# 月度趋势（日期列设为索引后按月重采样）
df = df.set_index("日期")
monthly = df["金额"].resample("ME").sum()
print("=== 月度趋势 ===")
print(monthly)

# ─── 4. 可视化（3 张图存成一张报告图）───
fig, axes = plt.subplots(2, 2, figsize=(12, 8))
cat_summary.plot.bar(x="品类", y="销售额", ax=axes[0, 0], title="品类销售额")
cat_summary.plot.bar(x="品类", y="销量", ax=axes[0, 1], title="品类销量", color="orange")
monthly.plot(ax=axes[1, 0], title="月度销售额趋势", marker="o")
city_summary.plot.bar(ax=axes[1, 1], title="城市销售额", color="green")
plt.tight_layout()
plt.savefig("销售分析报告.png", dpi=150)
plt.show()

# ─── 5. 导出结果 ───
cat_summary.to_csv("品类分析结果.csv", index=False, encoding="utf-8-sig")
print("已完成：销售分析报告.png + 品类分析结果.csv")
```

**完整数据链路**：`读取 → 清洗 → 分组聚合 → 可视化 → 导出`，这就是数据分析的标准流程。

### 面试高频题

| 问题 | 回答要点 |
| --- | --- |
| NumPy 比 list 快在哪？ | 底层 C 连续内存 + 向量化运算（免去 Python 循环解释开销）；broadcasting 自动扩展维度 |
| Series 和 DataFrame 区别？ | Series 一列（带索引）；DataFrame 多列表格（对标表/Excel）；DataFrame 由多个 Series 组成 |
| 怎么读 Excel/CSV/数据库？ | read_excel（需 openpyxl）/read_csv（encoding='utf-8-sig'）/read_sql（需 sqlalchemy） |
| 缺失值怎么处理？ | 探查 isnull().sum()；dropna() 删除 / fillna() 填充（数值列常用均值） |
| 分组聚合怎么做？ | df.groupby("列")["数值列"].agg(["sum","mean","count"])，对标 GROUP BY |
| 筛选条件注意什么？ | 用 & 和 | 而不是 and/or，且每个条件要加括号：`df[(df.a>1) & (df.b<2)]` |
| 透视表怎么做？ | pivot_table(index, columns, values, aggfunc)，对标 Excel 透视表 |
| 去重怎么做？ | drop_duplicates(subset=指定列, keep='first') |
| 如何发现异常值？ | describe() 看极值、箱线图、3σ 法则（mean±3*std） |
| 中文乱码怎么办？ | plt.rcParams['font.sans-serif']=['Microsoft YaHei']；CSV 读写用 utf-8-sig |
| pandas 和 SQL 怎么选？ | 数据在库里量大用 SQL 先粗筛；拿到内存后复杂清洗/分析/可视化用 Pandas |
| 大数据量怎么办？ | read_csv 的 chunksize 分块读；Dask/Polars 并行；先 SQL 聚合再拉 |
| 怎么保存图表？ | plt.savefig("x.png", dpi=150) 要在 plt.show() 前调用 |
| 向量化 vs 循环？ | 永远优先向量化（整列操作）；apply 是兜底；显式 for 循环是下策 |

### 本章小结

- **NumPy**（7.2）：ndarray、向量化运算、广播、布尔索引（对标 Java 数值流）；
- **Pandas**（7.3~7.5）：Series/DataFrame、数据读取四源、探查（info/describe）、清洗（缺失/重复/异常/类型）、筛选排序、**groupby 聚合**、merge/concat、透视表——一套操作对标 SQL 全系能力；
