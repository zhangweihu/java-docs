> 本章目标：学会用 NuGet 引用第三方包，掌握 .NET 内置“标准工具箱”：文件与目录（System.IO）、JSON（System.Text.Json）、网络（HttpClient）、日期时间、正则表达式、字符串处理、应用配置。之后你就能写“能干活”的真实工具了。

## 7.1 NuGet：.NET 的包仓库

NuGet 就像 Maven 的中央仓库 / pip。装包：

```bash
dotnet add package Newtonsoft.Json       # 或任意包名
```

装完可以在 `.csproj` 里看到 `<PackageReference Include="...">`。**一切以官方文档为准**：https://www.nuget.org

常用包速查（写作时的主流选择，版本请以 NuGet 为准）：

| 包 | 用途 | 备注 |
| --- | --- | --- |
| `System.Text.Json`（内置） | JSON 序列化 | .NET 内置，优先用 |
| `Newtonsoft.Json` | 老牌 JSON（生态兼容） | 老项目常见 |
| `Serilog` | 结构化日志 | 第 5 章提过 |
| `Microsoft.EntityFrameworkCore.*` | ORM | 第 8 章 |
| `Dapper` | 轻量 SQL 映射 | 第 8 章对比 |
| `HtmlAgilityPack` | 网页解析 | 爬虫 |
| `Spectre.Console` | 美化控制台输出 | 好玩且实用 |

> 选包原则：优先官方/微软维护（包前缀 `Microsoft.*`/`System.*`），再看下载量与更新时间。

## 7.2 System.IO：文件与目录

### 7.2.1 最简读写

```csharp
// 写
string path = @"C:\temp\hello.txt";          // Windows 示例；Linux 用 /tmp/hello.txt
Directory.CreateDirectory(Path.GetDirectoryName(path)!);   // 确保目录存在
File.WriteAllText(path, "第一行\n第二行");

// 读
string content = File.ReadAllText(path);
Console.WriteLine(content);

// 按行读
foreach (var line in File.ReadLines(path))
    Console.WriteLine("> " + line);

// 追加
File.AppendAllText(path, "追加一行\n");

// 删除 / 判断存在
Console.WriteLine(File.Exists(path));
File.Delete(path);
```

### 7.2.2 Path 组合路径（别手动拼字符串）

```csharp
string dir = Environment.GetFolderPath(Environment.SpecialFolder.MyDocuments);
string full = Path.Combine(dir, "data", "report.txt");   // 自动处理分隔符
Console.WriteLine(full);

Console.WriteLine(Path.GetFileName(full));      // report.txt
Console.WriteLine(Path.GetExtension(full));     // .txt
Console.WriteLine(Path.GetFileNameWithoutExtension(full)); // report
Console.WriteLine(Path.GetDirectoryName(full));
```

### 7.2.3 遍历目录

```csharp
string root = @"C:\temp";
if (!Directory.Exists(root)) return;

// 一层
foreach (var d in Directory.GetDirectories(root)) Console.WriteLine("[目录] " + d);
foreach (var f in Directory.GetFiles(root, "*.txt")) Console.WriteLine("[文件] " + f);

// 递归所有文件（搜索 .cs 源文件）
var allCs = Directory.EnumerateFiles(root, "*.cs", SearchOption.AllDirectories);
Console.WriteLine($"共 {allCs.Count()} 个 .cs 文件");
```

### 7.2.4 Stream：底层字节流

```csharp
// 大文件用流，避免一次性进内存
using var writer = new StreamWriter(@"C:\temp\big.txt");
for (int i = 0; i < 1000; i++) writer.WriteLine($"第 {i} 行");

using var reader = new StreamReader(@"C:\temp\big.txt");
string? line;
while ((line = reader.ReadLine()) != null)
{
    if (line.StartsWith("第 999")) Console.WriteLine(line);
}
```

> 已学的 `using` 在这里大显身手：`Stream` 用完必须释放，`using` 声明确保异常时也释放。

## 7.3 JSON：System.Text.Json

JSON 是 Web/配置文件的事实标准。核心三步：序列化（对象→字符串）、反序列化（字符串→对象）。

```csharp
// 1) 定义模型（纯数据用 record 或 class）
public record WeatherInfo(string City, double Temp, string Condition, int Humidity);

// 2) 序列化：对象 → JSON
var weather = new WeatherInfo("杭州", 24.5, "多云", 60);
string json = System.Text.Json.JsonSerializer.Serialize(weather,
    new System.Text.Json.JsonSerializerOptions { WriteIndented = true });
Console.WriteLine(json);
// {
//   "city": "杭州",
//   "temp": 24.5,
//   ...
// }

// 3) 反序列化：JSON → 对象
string input = """{"city":"北京","temp":18.2,"condition":"晴","humidity":40}""";
WeatherInfo? parsed = System.Text.Json.JsonSerializer.Deserialize<WeatherInfo>(input);
Console.WriteLine(parsed is null ? "解析失败" : $"{parsed.City} {parsed.Temp}℃ {parsed.Condition}");
```

### 7.3.1 命名策略与属性重命名

```csharp
var options = new System.Text.Json.JsonSerializerOptions
{
    PropertyNamingPolicy = System.Text.Json.JsonNamingPolicy.CamelCase,  // 属性→驼峰
    WriteIndented = true,
};

public record Product(
    [property: System.Text.Json.Serialization.JsonPropertyName("id")] int Id,
    [property: System.Text.Json.Serialization.JsonPropertyName("name")] string Name);
```

> 反序列化远端 API 时经常字段对不上，用 `JsonPropertyName` 显式映射最稳。

## 7.4 日期时间：DateTime / DateTimeOffset

```csharp
// 现在
DateTime now = DateTime.Now;                    // 本地时间
DateTime utc = DateTime.UtcNow;                 // UTC 时间

// 格式化
Console.WriteLine(now.ToString("yyyy-MM-dd HH:mm:ss"));
Console.WriteLine(now.ToString("yyyy年M月d日 dddd"));

// 解析
DateTime d1 = DateTime.Parse("2026-09-07");
Console.WriteLine(d1.DayOfWeek);                // Monday
Console.WriteLine(DateTime.TryParse("abc", out _));   // False

// 运算
Console.WriteLine(now.AddDays(10).AddHours(-1));
TimeSpan diff = DateTime.Now - d1;
Console.WriteLine($"相差 {diff.TotalDays:F1} 天");

// 计算年龄的实用函数
int Age(DateTime birth)
{
    var today = DateTime.Today;
    int age = today.Year - birth.Year;
    if (birth.Date > today.AddYears(-age)) age--;
    return age;
}
Console.WriteLine(Age(new DateTime(2014, 5, 1)));   // 约 12 岁（按 2026-09 算）
```

> **重要**：需要“带时区、可存库、要跨时区比较”的时间用 `DateTimeOffset`/UTC；纯日历（生日）用 `DateTime`。API 间传输通常用 ISO 8601 字符串或 Unix 时间戳。

## 7.5 正则表达式：模式匹配文本

`System.Text.RegularExpressions`。入门三步：`Regex.IsMatch`（是否匹配）、`Regex.Match`（取第一处）、`Regex.Matches`（取全部）。

```csharp
using System.Text.RegularExpressions;

// 1) 校验邮箱（简化版）
bool IsEmail(string s) => Regex.IsMatch(s, @"^[\w.-]+@[\w.-]+\.\w+$");
Console.WriteLine(IsEmail("a.b@example.com"));   // True
Console.WriteLine(IsEmail("not-an-email"));      // False

// 2) 提取：手机号
string text = "联系 13812345678 或 0571-88886666";
var matches = Regex.Matches(text, @"1[3-9]\d{9}");
foreach (Match m in matches) Console.WriteLine("手机号：" + m.Value);

// 3) 捕获组：提取日期 年 月 日
string date = "下单日期 2026-09-07，发货日期 2026-09-10";
Match md = Regex.Match(date, @"(\d{4})-(\d{2})-(\d{2})");
if (md.Success)
    Console.WriteLine($"年 {md.Groups[1].Value} 月 {md.Groups[2].Value} 日 {md.Groups[3].Value}");

// 4) 替换与切分
string masked = Regex.Replace("银行卡号 6222 0000 1111 2222", @"\d{4}", "****");
Console.WriteLine(masked);
```

> **建议**：先想清楚要匹配的模式再写正则，并先用 https://regex101.com 这类工具调试。复杂解析优先拆多步，别追求一行超长正则。
> `@""` 原样字符串里 `\d` 不用写成 `\\d`，这就是 `@` 的威力。

## 7.6 字符串进阶：StringBuilder 与常用操作

```csharp
// 大量拼接用 StringBuilder（循环里 + 会反复创建新字符串）
var sb = new System.Text.StringBuilder();
for (int i = 0; i < 1000; i++) sb.Append(i).Append(',');
string big = sb.ToString();

// 其它实用
string s = "Hello, C# World";
Console.WriteLine(s.Replace("C#", ".NET"));
Console.WriteLine(s.PadLeft(20));               // 左侧补空格对齐
Console.WriteLine(string.IsNullOrEmpty(""));    // True（注意三态：null/空/空白）

// 数值格式化
Console.WriteLine(string.Format("{0:N2}", 12345.678));   // 12,345.68
Console.WriteLine($"{0.125:P1}");                        // 12.5%
Console.WriteLine(123456m.ToString("C0"));                // 货币，0 位小数
```

## 7.7 应用配置：启动参数 / 环境变量 / 配置文件

真实程序不该把连接串等硬编码。

```csharp
// 1) 命令行参数
//    dotnet run -- --name=小明 --times 3
var args = Environment.GetCommandLineArgs();
// args[0] 是程序路径；后续才是参数。粗略手动解析：
for (int i = 1; i < args.Length; i++)
    if (args[i].StartsWith("--name=")) Console.WriteLine($"名字={args[i]["--name=".Length..]}");

// 2) 环境变量
string? mode = Environment.GetEnvironmentVariable("APP_MODE");
Console.WriteLine($"APP_MODE = {mode ?? "（未设置）"}");

// 3) appsettings.json（Web/宿主项目标配）
// {
//   "Logging": { "LogLevel": { "Default": "Information" } },
//   "Conn": "Data Source=app.db"
// }
// 读取代码在第 9 章讲 DI 配置时给出；控制台程序可手动：
var cfg = System.Text.Json.JsonSerializer.Deserialize<Dictionary<string, JsonElement>>(
    File.ReadAllText("appsettings.json"));
```

> 小结：**本地开发配置文件，生产用环境变量/机密管理**；不要把密钥提交到 Git。

## 7.8 完整可运行示例：天气查询 + 本地缓存

综合 JSON、HttpClient、文件、日期时间。**注意需要网络**，没网时也能跑（走缓存/演示数据）。

```csharp
using System.Text.Json;
using System.Text.RegularExpressions;

public record WeatherNow(string City, double Temp, string Text, int Humidity);

string CachePath(string city) => Path.Combine(Path.GetTempPath(), $"weather_{city}.json");

// 读缓存（10 分钟内有效）
WeatherNow? ReadCache(string city)
{
    string p = CachePath(city);
    if (!File.Exists(p)) return null;
    if (DateTime.Now - File.GetLastWriteTime(p) > TimeSpan.FromMinutes(10)) return null;
    return JsonSerializer.Deserialize<WeatherNow>(File.ReadAllText(p));
}

void SaveCache(string city, WeatherNow w)
{
    File.WriteAllText(CachePath(city), JsonSerializer.Serialize(w));
}

async Task<WeatherNow> FetchAsync(string city)
{
    using var client = new HttpClient();
    client.DefaultRequestHeaders.UserAgent.ParseAdd("csharp-learn/1.0");
    // 使用无需密钥的公开接口示例（wttr.in）
    string json = await client.GetStringAsync($"https://wttr.in/{city}?format=j1");
    using var doc = JsonDocument.Parse(json);
    var cur = doc.RootElement.GetProperty("current_condition")[0];
    string text = cur.GetProperty("weatherDesc")[0].GetProperty("value").GetString() ?? "";
    return new WeatherNow(city,
        cur.GetProperty("temp_C").GetDouble(),
        text,
        cur.GetProperty("humidity").GetInt32());
}

// —— 主流程 ——
Console.Write("输入城市（英文，如 hangzhou）：");
string city = Console.ReadLine()!.Trim();
if (!Regex.IsMatch(city, @"^[a-zA-Z-]+$")) { Console.WriteLine("城市名不合法"); return; }

WeatherNow weather = ReadCache(city) ?? await FetchAsync(city);
SaveCache(city, weather);

Console.WriteLine($"{weather.City}：{weather.Text}，{weather.Temp}℃，湿度 {weather.Humidity}%");
Console.WriteLine("（数据来自 wttr.in，若未联网请检查缓存逻辑）");
```

> 若本机无网络，观察文件缓存逻辑：重复运行第二次会直接读本地文件而不请求网络（体现在速度）。
