# 第二章 面向对象编程

> 本章目标：理解“面向对象”思想，掌握 C# 的类、对象、属性、构造器、封装、继承、多态、接口、抽象类与 `record`，会用“对象”建模现实业务。
> 前置：第一章。这是 C#（与 Java 同源）最核心的编程范式，务必多写。

## 2.1 为什么需要“面向对象”

想象你要做一个“学生管理系统”：每个学生有姓名、年龄、成绩；要能打印、能比较谁成绩高。用散装变量很痛苦：

```csharp
string name1 = "小明"; int age1 = 12; int score1 = 92;
string name2 = "小红"; int age2 = 11; int score2 = 88;
// 如果有 100 个学生呢？维护起来是灾难。
```

**面向对象（OOP）**的做法：把“一个学生”相关的数据（字段）和行为（方法）打包成一个 **类**，再用类批量造出很多 **对象**（实例）。

> 类 = 图纸；对象 = 按图纸造出来的实物。
> 对应关系：C#/Java 的 `class` ≈ Python 的 class ≈ Rust 的 `struct + impl`。

## 2.2 第一个类：字段、属性、方法

```csharp
// 文件：Student.cs（或与 Program.cs 放一起也行）
public class Student
{
    // —— 字段（数据）——
    private string _name;          // 约定：私有字段以下划线开头
    private int _age;
    private int _score;

    // —— 构造器：创建对象时自动调用，用来初始化 ——
    public Student(string name, int age, int score)
    {
        _name = name;
        _age = age;
        _score = score;
    }

    // —— 属性：对外提供受控的读写入口（推荐方式，替代直接暴露字段）——
    public string Name => _name;          // 只读属性（=> 表达式体）
    public int Age => _age;
    public int Score
    {
        get => _score;
        set
        {
            if (value < 0 || value > 100)
                throw new ArgumentOutOfRangeException(nameof(value), "成绩必须在 0~100 之间");
            _score = value;
        }
    }

    // —— 方法（行为）——
    public bool IsPassed() => _score >= 60;

    public string Describe() => $"{Name}：{Age} 岁，成绩 {Score}，{(IsPassed() ? "通过" : "未通过")}";
}

// —— 使用 ——
class Program
{
    static void Main()          // 传统写法演示；顶级语句时代你直接写也行
    {
        Student s = new Student("小明", 12, 92);
        Console.WriteLine(s.Describe());          // 小明：12 岁，成绩 92，通过
        s.Score = 55;                              // 走 set，校验通过
        Console.WriteLine(s.IsPassed());           // False
        // s.Score = 200;                          // 抛异常：超出 0~100
    }
}
```

### 2.2.1 关键概念逐个说

- **字段（field）**：类里的变量，保存对象状态；通常 `private`；
- **属性（property）**：带 `get`/`set` 的成员，是 C# 的招牌特性。外部像访问字段一样访问 `s.Score`，实际由你写逻辑控制读写。好处：可以在 `set` 里做**校验**，实现**封装**；
- **构造器（constructor）**：与类同名、没有返回类型的方法，`new` 时执行；
- **方法**：对象能做的行为；
- `value`：`set` 里自动可用的关键字，代表“外部赋进来的值”。

### 2.2.2 自动属性（最常用写法）

当属性不需要额外校验逻辑时，直接写：

```csharp
public class Product
{
    public string Name { get; set; } = "";      // 自动属性，编译器生成背后字段
    public decimal Price { get; set; }
    public int Stock { get; private set; }      // 只能类内部修改
}
```

### 2.2.3 对象初始化器

```csharp
var p = new Product { Name = "咖啡", Price = 28.5m, Stock = 100 };
// 效果等价于先 new 再逐个赋值
```

## 2.3 static：属于“类本身”的成员

前面学的成员属于“对象”。但有些东西不属于任何具体对象——如 `Math.PI`、`int.Parse`。用 `static` 标记：

```csharp
public class Counter
{
    public static int TotalCreated;           // 静态字段：全程序共享一份
    public int Id { get; }

    public Counter()
    {
        TotalCreated++;                        // 每 new 一次 +1
        Id = TotalCreated;
    }

    public static string Describe() => $"已创建 {TotalCreated} 个对象";
}

// 使用
var c1 = new Counter();
var c2 = new Counter();
Console.WriteLine(Counter.TotalCreated);      // 2：通过类名访问
Console.WriteLine(Counter.Describe());        // 已创建 2 个对象
```

- 静态成员用**类名**访问（`Counter.TotalCreated`），不需要 `new`；
- 记住经典区分：`Math.Max(1, 2)`（静态方法）vs `"abc".ToUpper()`（实例方法）。

## 2.4 封装与访问修饰符

封装 = 隐藏内部实现细节，只暴露需要的入口。访问修饰符决定谁能访问：

| 修饰符 | 谁能访问 |
| --- | --- |
| `public` | 任何地方 |
| `private` | 仅本类内部 |
| `protected` | 本类 + 子类 |
| `internal` | 同程序集（同一个工程）内 |
| `protected internal` / `private protected` | 组合语义，进阶再看 |

**经验法则**：字段一律 `private`（或 `private` + 公开属性）；方法默认从 `public` 或 `private` 里选；拿不准就先 `private`，需要再放开——这样天然形成“最小暴露面”。

## 2.5 继承：复用与扩展

子类用 `:` 继承父类，自动获得父类的公开成员，并可按需改写（覆写）。

```csharp
public class Animal
{
    public string Name { get; set; } = "";

    public Animal(string name) => Name = name;

    // virtual：允许子类覆写
    public virtual string Speak() => "...";
}

public class Dog : Animal
{
    public Dog(string name) : base(name) { }     // base(...) 调用父类构造器

    public override string Speak() => "汪汪！";   // override：真正覆写
}

public class Cat : Animal
{
    public Cat(string name) : base(name) { }
    public override string Speak() => "喵～";
}
```

```csharp
List<Animal> animals = new() { new Dog("旺财"), new Cat("咪咪") };
foreach (Animal a in animals)
{
    Console.WriteLine($"{a.Name} 说：{a.Speak()}");   // 各自说自己的
}
// 输出：旺财 说：汪汪！ / 咪咪 说：喵～
```

这就是**多态**：同一句 `a.Speak()`，运行时根据对象真实类型执行不同实现。

### 2.5.1 virtual / override / sealed / new

- 父类方法标记 `virtual`，子类才可以用 `override` 覆写；
- 子类不希望被继续继承 → 类加 `sealed`；不想让方法再被覆写 → 方法加 `sealed override`；
- 若子类方法故意“隐藏”而非覆写父类方法，用 `new` 关键字（少见，一般不需要）。

### 2.5.2 何时该用继承？

经典误区是“为了复用代码就继承”。正确判断标准是**is-a 关系**：狗 is-a 动物 ✓；但“员工 has-a 地址”应该用组合（对象里放一个地址对象）而不是继承。优先**组合优于继承**。

## 2.6 抽象类与接口

### 2.6.1 抽象类 abstract

父类太“空”，根本不该被 `new`（“动物”不该有具体实例），只负责定义骨架：

```csharp
public abstract class Shape
{
    public abstract double Area();   // 抽象方法：无实现，子类必须实现
    public void Print() => Console.WriteLine($"面积 = {Area()}");  // 普通方法
}

public class Circle : Shape
{
    public double Radius { get; }
    public Circle(double r) => Radius = r;
    public override double Area() => Math.PI * Radius * Radius;
}

public class Rect : Shape
{
    public double W { get; } public double H { get; }
    public Rect(double w, double h) { W = w; H = h; }
    public override double Area() => W * H;
}
```

```csharp
Shape s = new Circle(2);
s.Print();                 // 面积 = 12.566…
```

### 2.6.2 接口 interface

接口 = “能力契约”，只声明签名，不写实现。C# 一个类只能继承一个父类，但可以**实现多个接口**（这是多继承的替代方案）：

```csharp
public interface IChargeable
{
    double GetCharge();          // 方法签名（无实现）
}

public interface IDescribable
{
    string Describe();
}

// 同时实现两个接口
public class Account : IChargeable, IDescribable
{
    public string Owner { get; set; } = "";
    public decimal Balance { get; private set; }

    public double GetCharge() => (double)Balance * 0.001;   // 手续费示例
    public string Describe() => $"账户 {Owner}，余额 {Balance:C}";
}
```

```csharp
Account acc = new() { Owner = "小明" };
Console.WriteLine(acc.Describe());
Console.WriteLine($"手续费 {acc.GetCharge():F4}");
```

**抽象类 vs 接口（速记）**：

| | 抽象类 | 接口 |
| --- | --- | --- |
| 能不能有实现 | 能（部分成员有实现） | 默认实现可给，但主体是契约 |
| 继承数量 | 只能继承 1 个 | 可实现多个 |
| 语义 | “是什么”（is-a） | “能干什么”（能力） |
| 字段/状态 | 可以有 | 不可以有实例字段 |

**现代建议**：优先用接口表达“能力”（如可打印、可持久化、可计费）；用抽象类表达“家族骨架”。

## 2.7 object、ToString 与 is/as

- 所有类型都隐式继承自 `object`。`object` 引用任何东西；
- 每个类默认都有 `ToString()`，建议覆写以输出友好文本：

```csharp
public class User
{
    public string Name { get; set; } = "";
    public override string ToString() => $"用户：{Name}";
}

User u = new() { Name = "小红" };
Console.WriteLine(u.ToString());      // 用户：小红
Console.WriteLine(u);                 // WriteLine 会自动调用 ToString()
```

- 类型判断与转换：`is`（判断能否转换）/ `as`（安全转换，失败给 null）：

```csharp
object obj = "hello";
Console.WriteLine(obj is string);        // True
string? text = obj as string;            // 成功 → "hello"
Console.WriteLine(text?.ToUpper());      // HELLO

object num = 42;
string? bad = num as string;             // 失败 → null（不抛异常）
Console.WriteLine(bad is null);          // True
```

`obj as string` 失败返回 `null`，配合 `?.`（null 条件运算符，第 5 章）可安全访问。

## 2.8 record：面向数据的类型（C# 9+）

写“数据搬运类”（DTO、值对象）时，传统 class 要写一堆样板：构造、相等比较、ToString。`record` 一行搞定：

```csharp
public record OrderItem(string ProductName, int Qty, decimal UnitPrice)
{
    public decimal Total => Qty * UnitPrice;    // 还能加计算属性
}

var o1 = new OrderItem("咖啡", 2, 25m);
var o2 = new OrderItem("咖啡", 2, 25m);
Console.WriteLine(o1 == o2);        // True：按“值”比较（class 默认按引用比较）
Console.WriteLine(o1.Total);        // 50
var o3 = o1 with { Qty = 3 };       // with：复制并修改（o1 不变）
Console.WriteLine(o1);              // OrderItem { ProductName = 咖啡, Qty = 2, ... }
```

- `record`（默认引用类型）自动提供：位置构造、`==`/`Equals` 值比较、`ToString`、`with` 表达式、解构；
- 想让它不可变：`public record Foo(...)` 的 `init` 属性天然只读（`init` 只能在构造或对象初始化器里赋值）；
- `record struct`（C# 10+）则是值类型版本。

**选择建议**：领域里有行为、有状态、会被改 → `class`；纯数据、需要按值比较 → `record`。

## 2.9 命名空间 namespace 与 using

工程大了，类型多了会重名。用命名空间归类：

```csharp
// 文件 MyLib.cs
namespace MyLibrary.Utilities
{
    public class StringHelper
    {
        public static bool IsBlank(string? s) => string.IsNullOrWhiteSpace(s);
    }
}
```

```csharp
// 文件 Program.cs
using MyLibrary.Utilities;

Console.WriteLine(StringHelper.IsBlank("   "));   // True
```

- 文件的类前面加的 `using Xxx;` 是“导入命名空间”，这样不用写全名；
- 现代 .NET 项目默认启用**隐式 using**（自动 using 常用命名空间如 `System`、`System.Linq`、`System.IO`），所以你直接写 `Console`、`List<int>` 不用手动 `using System;`。

## 2.10 完整可运行示例：银行账户体系

把下面内容组织成两个文件（或都在 `Program.cs`，类写在顶级语句之后）：

```csharp
// —— 接口：账户能力契约 ——
public interface IAccount
{
    string AccountNo { get; }
    decimal Balance { get; }
    void Deposit(decimal amount);          // 存钱
    void Withdraw(decimal amount);         // 取钱（余额不足抛异常）
    string Describe();
}

// —— 抽象基类：公共骨架 ——
public abstract class AccountBase : IAccount
{
    public string AccountNo { get; }
    public decimal Balance { get; protected set; }     // 子类可修改

    protected AccountBase(string accountNo, decimal init)
    {
        AccountNo = accountNo;
        Balance = init;
    }

    public void Deposit(decimal amount)
    {
        if (amount <= 0) throw new ArgumentException("存款金额必须为正数");
        Balance += amount;
    }

    public void Withdraw(decimal amount)
    {
        if (amount <= 0) throw new ArgumentException("取款金额必须为正数");
        if (amount > Balance) throw new InvalidOperationException("余额不足");
        Balance -= amount;
    }

    public abstract string Describe();     // 子类给出各自的描述
}

// —— 储蓄账户 ——
public sealed class SavingAccount : AccountBase
{
    public decimal InterestRate { get; }                 // 年利率
    public SavingAccount(string no, decimal init, decimal rate)
        : base(no, init) => InterestRate = rate;

    public decimal CalcYearInterest() => Balance * InterestRate;

    public override string Describe() =>
        $"储蓄账户 {AccountNo}：余额 {Balance:C}，年利率 {InterestRate:P}";
}

// —— 信用卡（假设支持透支）——
public class CreditAccount : AccountBase
{
    public decimal Limit { get; }
    public CreditAccount(string no, decimal limit)
        : base(no, 0) => Limit = limit;

    public override void Withdraw(decimal amount)       // 覆写：允许透支到额度上限
    {
        if (amount <= 0) throw new ArgumentException("取款金额必须为正数");
        if (Balance - amount < -Limit) throw new InvalidOperationException("超过信用额度");
        Balance -= amount;
    }

    public override string Describe() =>
        $"信用卡 {AccountNo}：当前欠款 {(-Balance):C}（额度 {Limit:C}）";
}
```

```csharp
// —— 顶级语句使用 ——
var accounts = new List<IAccount>
{
    new SavingAccount("SA-001", 1000m, 0.02m),
    new CreditAccount("CR-001", 5000m),
};

accounts[0].Deposit(500m);
accounts[1].Withdraw(800m);              // 信用卡透支 800

foreach (var acc in accounts)
    Console.WriteLine(acc.Describe());

var sa = (SavingAccount)accounts[0];     // 接口转具体类（这里安全，因为确实是它）
Console.WriteLine($"一年利息：{sa.CalcYearInterest():C}");
```

## 语言对照

| 概念 | C# | Java | Python | Rust |
| --- | --- | --- | --- | --- |
| 类 | `class` | `class` | `class` | `struct` + `impl` |
| 继承 | `:` / `: base()` | `extends` / `super()` | 括号继承 | trait 继承/组合 |
| 接口 | `interface` | `interface` | ABC/protocol | `trait` |
| 覆写 | `override` | `@Override` | 直接覆写 | `impl` 同名方法 |
| 构造器 | 同名方法 + `new` | 同名方法 | `__init__` | `new()` 关联函数 |
| 属性 | 语言级 property | getter/setter 方法 | `@property` | 方法 |
| 值相等数据类 | `record` | `record`（16+） | `dataclass` | 派生 `PartialEq` |
| 所有类型基类 | `object` | `Object` | 一切皆对象 | 无统一基类 |
