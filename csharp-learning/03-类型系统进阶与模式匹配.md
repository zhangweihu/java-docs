# 第三章 类型系统进阶与模式匹配

> 本章目标：吃透 C# 的类型体系——`struct` 与 `class` 的本质差异、枚举、元组、可空类型（`?` / `??` / `?.`），并掌握 C# 的招牌语法 **模式匹配与 switch 表达式**，写出更安全、更简洁的代码。
> 前置：第一、二章。

## 3.1 struct：值类型

第二章的 `class` 是**引用类型**：变量里存的是“指向堆上对象的引用”。而 `struct` 是**值类型**：变量直接存数据本体。

```csharp
// 类：引用类型
public class PointClass { public int X; public int Y; }

// 结构体：值类型
public struct Point
{
    public int X;
    public int Y;
    public Point(int x, int y) { X = x; Y = y; }
    public double DistanceTo(Point other)
        => Math.Sqrt((X - other.X) * (X - other.X) + (Y - other.Y) * (Y - other.Y));
}
```

```csharp
var p1 = new Point(1, 1);
var p2 = p1;                 // p2 复制了 p1 的数据（两份独立数据）
p2.X = 100;
Console.WriteLine(p1.X);     // 1  ← p1 不受影响（值类型是“复制”）

var c1 = new PointClass { X = 1, Y = 1 };
var c2 = c1;                 // c2 与 c1 指向同一个对象
c2.X = 100;
Console.WriteLine(c1.X);     // 100  ← 引用类型是“共享同一个对象”
```

| | class（引用类型） | struct（值类型） |
| --- | --- | --- |
| 变量存什么 | 引用（地址） | 数据本体 |
| 赋值行为 | 共享同一对象 | 完整复制 |
| 存放位置 | 堆 | 栈（内联于所在容器） |
| 判空 | 可为 null | 默认不可为 null（`?` 包一层才行） |
| `==` 默认 | 比较引用 | 比较字段（按值） |
| 适用 | 实体、有行为的领域对象 | 小体积、频繁创建、语义就是“值”（坐标/颜色/金额） |

**选择经验**：拿不准就用 `class`。体积小（几十字节内）且代表“值”的（坐标、日期区间、RGB）才考虑 `struct`。别为“性能”过早优化（第 11 章内存专题再深挖）。

> `record` 可以是 `record struct`（值语义的数据类型）；C# 10+ 还允许 struct 有无参构造器与字段初始化器。

## 3.2 枚举 enum

枚举：给一组**命名的常量**定类型，让代码可读且防错（比到处写魔数强）：

```csharp
public enum OrderStatus
{
    Pending = 0,     // 可显式给值；不给则自动从 0 递增
    Paid = 1,
    Shipped = 2,
    Done = 3,
    Cancelled = 4,
}

public enum Weekday { Mon, Tue, Wed, Thu, Fri, Sat, Sun }
```

```csharp
OrderStatus status = OrderStatus.Paid;

switch (status)
{
    case OrderStatus.Paid:
        Console.WriteLine("已支付，待发货");
        break;
    case OrderStatus.Shipped:
    case OrderStatus.Done:
        Console.WriteLine("物流或已完成");
        break;
    default:
        Console.WriteLine("其它状态");
        break;
}

// 常用转换
Console.WriteLine((int)OrderStatus.Paid);        // 1：枚举 → 数字
Console.WriteLine((OrderStatus)2);               // Shipped：数字 → 枚举
Console.WriteLine(Enum.GetName(typeof(OrderStatus), 3)); // Done
string[] names = Enum.GetNames<OrderStatus>();   // 所有名字数组
foreach (var n in names) Console.Write(n + " ");

// 判断枚举是否合法（解析用户输入时很有用）
bool ok = Enum.TryParse<OrderStatus>("Paid", out var s2);
Console.WriteLine($"解析 {ok} -> {s2}");
```

- 内部其实就是整数，但禁止随意把任意数字当状态用（需要显式转换）；
- 给枚举加“描述文本”可用 `[Description]` 特性或扩展方法（第 4 章扩展方法会再次出现）。

## 3.3 元组 tuple

临时把几个值打包，不想专门建类/record 时用元组：

```csharp
// 元组字面量：圆括号
var person = ("小明", 12);
Console.WriteLine(person.Item1);     // 小明
Console.WriteLine(person.Item2);     // 12

// 给元素命名（更可读）
var score = (name: "小红", value: 98.5);
Console.WriteLine($"{score.name} 得了 {score.value}");

// 方法返回多个值（最常见用途）
(int min, int max, double avg) Stats(int[] arr)
{
    int min = arr[0], max = arr[0], sum = 0;
    foreach (var v in arr) { if (v < min) min = v; if (v > max) max = v; sum += v; }
    return (min, max, (double)sum / arr.Length);
}

var (mn, mx, av) = Stats(new[] { 3, 8, 1, 9, 4 });   // 解构
Console.WriteLine($"{mn} {mx} {av:F1}");             // 1 9 5.0

// 丢弃用 _：只关心部分返回值
var (_, _, onlyAvg) = Stats(new[] { 1, 2, 3 });
Console.WriteLine(onlyAvg);
```

## 3.4 可空类型：与 null 打交道

真实程序里数据经常“可能没有值”。C# 用一套系统化语法安全地处理 null。

### 3.4.1 可空值类型 `int?`

值类型默认不能是 null。加 `?` 表示“可空”：

```csharp
int? age = null;              // “年龄未知”
age = 12;

// 取值三种方式
Console.WriteLine(age.HasValue);          // 是否有值
Console.WriteLine(age.Value);             // 直接取（没值会抛异常！）

int safe1 = age.GetValueOrDefault();      // 有值取值，没值取 0
int safe2 = age ?? 0;                     // ?? ：左边为 null 就用右边的默认值（最常用）
Console.WriteLine($"{safe1} {safe2}");
```

### 3.4.2 null 条件运算符 `?.`

只在一连串访问的任意环节为 null 时整体短路为 null：

```csharp
string? name = MaybeGetName();   // 可能返回 null

// 没有 ?. 会怎样？name.Length → 如果 name 是 null 就抛 NullReferenceException
int len = name?.Length ?? 0;     // name 为 null → 整个 name?.Length 为 null → ?? 兜底为 0
Console.WriteLine(len);

// 链式：?. 中间任何一层为 null 都安全（但要注意返回值已是可空）
```

注意：`name?.ToUpper()` 的结果类型是 `string?`，若继续写 `.Substring(...)`，编译器会提示“可能为 null”。正确写法如下：

```csharp
string? a = null;
int l = a?.Length ?? 0;                        // ✅
string? b = a?.Trim();                          // ✅ b 是 string?
```

想“只要不是 null 就执行整个方法”：

```csharp
name?.Trim();       // name 为 null 则整句不执行，否则执行 Trim()
```

### 3.4.3 可空引用类型（C# 8+）

现代 .NET 工程默认开启 `<Nullable>enable</Nullable>`，编译器把 `string` 与 `string?` 分开：普通 `string` 表示“我保证不是 null”，`string?` 表示“可能为 null”。好处：很多空引用错误在**编译期**就被提示（黄色波浪线，如 CS8602）。

```csharp
string notNull = "我有值";
string? maybe = Console.ReadLine();   // 用户输入可能没有 → 必须写成 string?

// 编译器会提示：maybe.ToUpper() 可能空引用
// 正确做法：
if (maybe is not null)                // 判空后，编译器知道已安全
    Console.WriteLine(maybe.ToUpper());

Console.WriteLine(maybe?.ToUpper() ?? "（没有输入）");   // 或 ?. + ??
```

> 有时你“确信”它不是 null（比如从三方接口拿到的数据），可以用**空值断言 `!`** 告诉编译器别管：`maybe!.Length`。但这只是骗过编译器，运行时仍可能炸，**少用**。

## 3.5 模式匹配：让 switch 脱胎换骨

C# 7 起模式匹配逐年增强，到 C# 8+ 已经能写出非常优雅的分支逻辑。

### 3.5.1 switch 表达式（C# 8+）

传统 switch 是语句；switch **表达式**是“一个值换一个值”：

```csharp
OrderStatus s = OrderStatus.Shipped;
string desc = s switch
{
    OrderStatus.Pending   => "待支付",
    OrderStatus.Paid      => "已支付",
    OrderStatus.Shipped   => "运输中",
    OrderStatus.Done      => "已完成",
    OrderStatus.Cancelled => "已取消",
    _ => "未知",                     // _ 是“默认分支”，必写（穷尽性检查）
};
Console.WriteLine(desc);
```

### 3.5.2 在类型上匹配：is + when

```csharp
object o = 42;
if (o is int i)
{
    Console.WriteLine($"是 int，值 {i}，加 1 得 {i + 1}");   // 匹配时自动把 o 当 int 用
}

string Describe2(object value) => value switch
{
    int n when n < 0           => $"负数 {n}",
    int n                      => $"非负整数 {n}",
    string s when s.Length > 5 => $"长文本（{s.Length} 字）",
    string s                   => $"短文本：{s}",
    null                       => "是空",
    _                          => $"未知类型 {value.GetType().Name}",
};

Console.WriteLine(Describe2(-5));        // 负数 -5
Console.WriteLine(Describe2("你好"));    // 短文本：你好
```

`when` 是**守卫条件**，按从上到下的顺序匹配，第一个命中生效。

### 3.5.3 属性模式与关系模式（C# 9）

```csharp
record Weather(int Temp, bool Rainy);

string Advice(Weather w) => w switch
{
    { Temp: < 0, Rainy: true }                 => "冰雨！别出门",
    { Temp: >= 30 }                            => "注意防暑",
    { Rainy: true }                            => "带伞",
    _                                          => "天气不错",
};
// 简化：外层 {} 可省略（C# 10+）
string Advice2(Weather w) => w switch
{
    { Temp: < 0 } and { Rainy: true } => "冰雨！",
    { Temp: >= 30 } => "防暑",
    { Rainy: true } => "带伞",
    _ => "不错",
};

Console.WriteLine(Advice(new Weather(-2, true)));   // 冰雨！别出门
Console.WriteLine(Advice(new Weather(33, false)));  // 注意防暑
```

- 关系模式：`< 0`、`>= 30`（C# 9+），配合 `and`/`or`/`not` 组合逻辑；
- 解构/位置模式：`if (p is (0, 0))` 匹配坐标原点。

### 3.5.4 列表模式（C# 11）

```csharp
int[] arr = { 1, 2, 3 };

string Judge(int[] xs) => xs switch
{
    []                       => "空数组",
    [var first]              => $"只有一个元素 {first}",
    [_, _, var third]        => $"至少三个，第三个是 {third}",
    [var a, var b, ..]       => $"开头两个是 {a}、{b}",
    _                        => "其它",
};
Console.WriteLine(Judge(arr));    // 至少三个，第三个是 3
```

## 3.8 完整可运行示例：支付方式判断 + 折扣引擎

```csharp
// 支付方式：现金 / 微信 / 支付宝 / 银行卡
public enum PayMethod { Cash, WeChat, Alipay, BankCard }

// 订单（用 record 表达纯数据）
public record Order(decimal Amount, PayMethod Method, int MemberLevel);

public static class OrderRules
{
    // 1) 判断支付方式是否被支持
    public static bool IsSupported(PayMethod m) => m switch
    {
        PayMethod.WeChat or PayMethod.Alipay or PayMethod.BankCard => true,
        PayMethod.Cash => false,     // 线上订单不收现金
        _ => false,
    };

    // 2) 计算应付金额：会员等级折扣 + 支付方式补贴
    public static decimal Payable(Order o) => o switch
    {
        { MemberLevel: >= 3 } and { Amount: >= 500 } => Apply(o.Amount, 0.8m),
        { MemberLevel: >= 2 } and { Amount: >= 200 } => Apply(o.Amount, 0.9m),
        { Amount: >= 1000 }                          => Apply(o.Amount, 0.85m),
        _ => o.Amount,
    };

    private static decimal Apply(decimal amount, decimal rate)
        => decimal.Round(amount * rate, 2);
}

// 测试
var orders = new[]
{
    new Order(1200m, PayMethod.WeChat, 1),   // 超 1000 → 85 折
    new Order(600m, PayMethod.Alipay, 3),    // 会员3级且≥500 → 8 折
    new Order(50m, PayMethod.Cash, 1),       // 现金且金额小 → 原价
};

foreach (var o in orders)
{
    string pay = o.Method.ToString();
    if (!OrderRules.IsSupported(o.Method)) Console.WriteLine($"{pay} 不支持线上支付");
    else Console.WriteLine($"{pay} 应付 {OrderRules.Payable(o):C}");
}
```

## 3.10 小结

类型系统是 C# 的“第一生产力”：值/引用语义让你理解数据流动，可空类型把“运行时才炸的空引用”提前到编译期提示，模式匹配让分支逻辑又安全又好读。这套能力马上会在 LINQ 和 Web 处理中反复使用。

| 概念 | C# | Java | Python | Rust |
| --- | --- | --- | --- | --- |
