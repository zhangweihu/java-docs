# 第五章 多线程与并发

> 本章掌握：线程的创建方式、线程生命周期、同步与锁、线程通信、线程池。
> 并发是 Java 开发的进阶重点，也是面试高频考点。

## 5.1 进程与线程

- **进程**：运行中的程序，有独立的内存空间（如一个浏览器）。
- **线程**：进程内的执行单元，多个线程**共享**进程的内存（堆、方法区），但各有独立的栈。

多线程的意义：**充分利用 CPU，提高程序执行效率**（下载、并发请求、大量计算等场景）。

## 5.2 创建线程的 3 种方式

### 方式一：继承 Thread 类

```java
public class MyThread extends Thread {
    private String name;

    public MyThread(String name) {
        this.name = name;
    }

    @Override
    public void run() {
        for (int i = 1; i <= 5; i++) {
            System.out.println(name + " 执行第 " + i + " 次");
            try {
                Thread.sleep(200);   // 休眠 200 毫秒
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }

    public static void main(String[] args) {
        // 创建并启动线程（start() 内部会调用 run()）
        MyThread t1 = new MyThread("线程A");
        MyThread t2 = new MyThread("线程B");
        t1.start();
        t2.start();
        System.out.println("main 线程继续执行");
    }
}
```

> 注意：必须调用 `start()` 启动线程，直接调用 `run()` 只是普通方法调用。

### 方式二：实现 Runnable 接口（推荐）

```java
public class RunnableDemo {
    public static void main(String[] args) {
        // Lambda 方式创建 Runnable
        Runnable task = () -> {
            for (int i = 1; i <= 5; i++) {
                System.out.println(Thread.currentThread().getName() + " 计数：" + i);
                try {
                    Thread.sleep(100);
                } catch (InterruptedException e) {
                    e.printStackTrace();
                }
            }
        };

        Thread t1 = new Thread(task, "工作线程-1");
        Thread t2 = new Thread(task, "工作线程-2");
        t1.start();
        t2.start();

        // 主线程也做自己的事
        for (int i = 0; i < 3; i++) {
            System.out.println("main 线程工作：" + i);
        }
    }
}
```

### 方式三：实现 Callable 接口（带返回值）

```java
import java.util.concurrent.Callable;
import java.util.concurrent.ExecutionException;
import java.util.concurrent.FutureTask;

public class CallableDemo {
    public static void main(String[] args) throws ExecutionException, InterruptedException {
        // Callable 可以返回结果、抛出异常
        Callable<Integer> task = () -> {
            int sum = 0;
            for (int i = 1; i <= 100; i++) {
                sum += i;
                Thread.sleep(1);
            }
            return sum;
        };

        // FutureTask 包装 Callable
        FutureTask<Integer> futureTask = new FutureTask<>(task);
        Thread t = new Thread(futureTask);
        t.start();

        // get() 会阻塞等待线程执行完成并拿到结果
        int result = futureTask.get();
        System.out.println("1~100 的和 = " + result);
    }
}
```

## 5.3 线程生命周期

```
新建(New) → 就绪(Runnable) → 运行(Running) → 终止(Terminated)
              ↑                    │
              └──── 等待/阻塞(Waitting/Blocked) ←──┘
```

- `new Thread()` → 新建
- `start()` → 就绪（等待 CPU 调度）
- CPU 调度 → 运行
- `sleep()` / `wait()` / 锁阻塞 → 等待/阻塞
- `run()` 执行完毕 → 终止

## 5.4 线程安全问题与 synchronized

多个线程同时访问**共享数据**时会产生数据不一致问题（竞态条件）。

### 5.4.1 问题演示（卖票）

```java
public class TicketDemo {
    public static void main(String[] args) {
        // 共享资源：50 张票，3 个窗口同时卖
        TicketWindow window = new TicketWindow();
        new Thread(window, "窗口1").start();
        new Thread(window, "窗口2").start();
        new Thread(window, "窗口3").start();
    }
}

// 有线程安全问题
class TicketWindow implements Runnable {
    private int tickets = 50;

    @Override
    public void run() {
        while (tickets > 0) {
            try {
                Thread.sleep(10);   // 模拟业务耗时，放大问题
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
            System.out.println(Thread.currentThread().getName() + " 卖出了第 " + tickets + " 张票");
            tickets--;
        }
    }
}
```

运行结果会出现：同一张票被卖出多次、甚至卖出负票 → **数据竞争**。

### 5.4.2 解决方案：synchronized 同步锁

```java
// 方式一：同步方法（锁住整个方法）
class TicketWindow2 implements Runnable {
    private int tickets = 50;

    @Override
    public synchronized void run() {   // 同步方法：同一时刻只有一个线程执行
        while (tickets > 0) {
            try {
                Thread.sleep(10);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
            System.out.println(Thread.currentThread().getName() + " 卖出了第 " + tickets + " 张票");
            tickets--;
        }
    }
}
```

```java
// 方式二：同步代码块（锁住关键代码，效率更高）
class TicketWindow3 implements Runnable {
    private int tickets = 50;
    private final Object lock = new Object();   // 锁对象

    @Override
    public void run() {
        while (true) {
            synchronized (lock) {    // 同步代码块
                if (tickets <= 0) {
                    break;
                }
                try {
                    Thread.sleep(10);
                } catch (InterruptedException e) {
                    e.printStackTrace();
                }
                System.out.println(Thread.currentThread().getName() + " 卖出了第 " + tickets + " 张票");
                tickets--;
            }
        }
    }
}
```

### 5.4.3 使用 Lock 接口（JDK5+ 更灵活）

```java
import java.util.concurrent.locks.Lock;
import java.util.concurrent.locks.ReentrantLock;

class TicketWindow4 implements Runnable {
    private int tickets = 50;
    // 可重入锁：比 synchronized 更灵活（可中断、可尝试获取、公平锁）
    private final Lock lock = new ReentrantLock();

    @Override
    public void run() {
        while (true) {
            lock.lock();   // 加锁
            try {
                if (tickets <= 0) {
                    break;
                }
                Thread.sleep(10);
                System.out.println(Thread.currentThread().getName() + " 卖出了第 " + tickets + " 张票");
                tickets--;
            } catch (InterruptedException e) {
                e.printStackTrace();
            } finally {
                lock.unlock();   // 必须释放锁（finally 中）
            }
        }
    }
}
```

### synchronized vs Lock 对比

| 对比项 | synchronized | Lock |
| --- | --- | --- |
| 锁的获取 | 自动 | 手动（lock/unlock） |
| 释放 | 代码块结束自动释放 | 必须 finally 中手动释放 |
| 可中断 | 不支持 | 支持 `lockInterruptibly()` |
| 公平锁 | 非公平 | 可指定公平 |
| 性能 | JDK6 优化后与 Lock 接近 | 高并发下表现更好 |

## 5.5 volatile 与原子类

```java
import java.util.concurrent.atomic.AtomicInteger;

public class VolatileDemo {
    public static void main(String[] args) throws InterruptedException {
        // 问题：多个线程对共享变量++，结果 < 期望值
        Counter counter = new Counter();
        Thread[] threads = new Thread[100];
        for (int i = 0; i < 100; i++) {
            threads[i] = new Thread(() -> {
                for (int j = 0; j < 1000; j++) {
                    counter.increment();
                }
            });
            threads[i].start();
        }
        for (Thread t : threads) {
            t.join();   // 等待所有线程结束
        }
        System.out.println("最终值（应为100000）：" + counter.get());
    }
}

class Counter {
    // volatile：保证可见性（一个线程修改，其他线程立即看到），但不保证原子性
    private volatile int count = 0;

    public synchronized void increment() {   // synchronized 保证原子性
        count++;
    }

    public int get() {
        return count;
    }
}
```

```java
// 更优方案：原子类（CAS 实现，无锁，性能高）
class AtomicCounter {
    private AtomicInteger count = new AtomicInteger(0);

    public void increment() {
        count.incrementAndGet();   // 原子操作
    }

    public int get() {
        return count.get();
    }
}
```

> **volatile vs synchronized**：volatile 解决"可见性"，不解决"原子性"；synchronized 两者都解决。

## 5.6 线程通信：wait / notify

生产者-消费者模式是线程通信的经典案例。

```java
import java.util.LinkedList;
import java.util.Queue;

public class ProducerConsumerDemo {
    public static void main(String[] args) {
        // 共享的缓冲区（容量为 5）
        Buffer buffer = new Buffer(5);

        // 生产者：生产 10 个数据
        new Thread(() -> {
            for (int i = 1; i <= 10; i++) {
                buffer.put(i);
            }
        }, "生产者").start();

        // 消费者：消费数据
        new Thread(() -> {
            for (int i = 1; i <= 10; i++) {
                buffer.take();
            }
        }, "消费者").start();
    }
}

// 缓冲区
class Buffer {
    private final Queue<Integer> queue = new LinkedList<>();
    private final int capacity;

    public Buffer(int capacity) {
        this.capacity = capacity;
    }

    // 生产
    public synchronized void put(int value) {
        while (queue.size() >= capacity) {
            try {
                System.out.println("缓冲区已满，生产者等待...");
                wait();   // 等待，释放锁
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
        queue.offer(value);
        System.out.println("生产了：" + value + "，当前数量：" + queue.size());
        notifyAll();   // 唤醒所有等待的线程
    }

    // 消费
    public synchronized int take() {
        while (queue.isEmpty()) {
            try {
                System.out.println("缓冲区为空，消费者等待...");
                wait();
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
        int value = queue.poll();
        System.out.println("  消费了：" + value + "，剩余数量：" + queue.size());
        notifyAll();
        return value;
    }
}
```

> `wait()` 会释放锁并进入等待；`notify()` 随机唤醒一个线程，`notifyAll()` 唤醒所有线程。
> 注意：必须在同步块中调用 `wait/notify`。

## 5.7 线程池（ThreadPoolExecutor）

频繁创建/销毁线程开销大，用**线程池**复用线程。

### 5.7.1 使用 Executors 工具类（简单场景）

```java
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;

public class ExecutorsDemo {
    public static void main(String[] args) {
        // 固定大小线程池：3 个线程
        ExecutorService pool = Executors.newFixedThreadPool(3);

        // 提交 10 个任务
        for (int i = 1; i <= 10; i++) {
            final int taskId = i;
            pool.execute(() -> {
                System.out.println(Thread.currentThread().getName() + " 执行任务 " + taskId);
                try {
                    Thread.sleep(100);
                } catch (InterruptedException e) {
                    e.printStackTrace();
                }
            });
        }

        // 关闭线程池（不再接受新任务，执行完已有的任务后关闭）
        pool.shutdown();
        // pool.shutdownNow();  // 立即关闭
    }
}
```

### 5.7.2 手动创建线程池（生产推荐）

```java
import java.util.concurrent.ArrayBlockingQueue;
import java.util.concurrent.ThreadPoolExecutor;
import java.util.concurrent.TimeUnit;

public class ThreadPoolDemo {
    public static void main(String[] args) {
        /*
         * 参数说明：
         * corePoolSize    核心线程数（常驻）
         * maximumPoolSize 最大线程数
         * keepAliveTime   非核心线程空闲存活时间
         * unit            时间单位
         * workQueue       任务队列（超出核心线程数的任务排队）
         * threadFactory   线程工厂（可选）
         * handler         拒绝策略（可选）
         */
        ThreadPoolExecutor pool = new ThreadPoolExecutor(
                2,                          // 核心线程数
                5,                          // 最大线程数
                60L,                        // 空闲存活时间
                TimeUnit.SECONDS,           // 时间单位
                new ArrayBlockingQueue<>(10) // 有界任务队列
        );

        // 模拟提交 15 个任务
        for (int i = 1; i <= 15; i++) {
            final int n = i;
            pool.execute(() -> {
                System.out.println(Thread.currentThread().getName() + " 处理任务 " + n);
                try {
                    Thread.sleep(200);
                } catch (InterruptedException e) {
                    e.printStackTrace();
                }
            });
        }

        pool.shutdown();
        System.out.println("线程池已提交全部任务");
    }
}
```

> **阿里巴巴开发规范**：禁止使用 `Executors` 创建线程池（容易出现 OOM），建议手动创建 `ThreadPoolExecutor`。
> 常见拒绝策略：`AbortPolicy`（抛异常，默认）、`CallerRunsPolicy`（调用者执行）、`DiscardPolicy`（丢弃）。

## 5.8 其他并发工具

```java
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.CyclicBarrier;
import java.util.concurrent.Semaphore;

public class ConcurrencyToolsDemo {
    public static void main(String[] args) throws InterruptedException {
        // ========== CountDownLatch：等待多个线程完成 ==========
        CountDownLatch latch = new CountDownLatch(3);   // 计数器为 3
        for (int i = 0; i < 3; i++) {
            new Thread(() -> {
                try {
                    Thread.sleep((long) (Math.random() * 500));
                } catch (InterruptedException e) {
                    e.printStackTrace();
                }
                System.out.println(Thread.currentThread().getName() + " 完成任务");
                latch.countDown();   // 计数器减 1
            }).start();
        }
        latch.await();   // 主线程等待计数器归零
        System.out.println("所有任务完成，主线程继续");

        // ========== Semaphore：限流（同时最多 N 个线程）==========
        Semaphore semaphore = new Semaphore(2);   // 2 个许可
        for (int i = 0; i < 5; i++) {
            new Thread(() -> {
                try {
                    semaphore.acquire();   // 获取许可
                    System.out.println(Thread.currentThread().getName() + " 进入，剩余许可 "
                            + semaphore.availablePermits());
                    Thread.sleep(300);
                } catch (InterruptedException e) {
                    e.printStackTrace();
                } finally {
                    semaphore.release();   // 释放许可
                }
            }).start();
        }
    }
}
```
