# 第二章 面向对象编程（OOP）

> 面向对象是 Java 的核心思想：**万物皆对象**。本章掌握类与对象、封装、继承、多态、抽象类与接口。
> Java 三大特征：**封装、继承、多态**。

## 2.1 类与对象

**类（Class）** 是模板/蓝图，**对象（Object）** 是根据模板创建的具体实例。

```java
// 定义一个学生类
public class Student {
    // 属性（成员变量 / 字段）
    String name;
    int age;
    String major;

    // 方法（行为）
    void introduce() {
        System.out.println("我是 " + name + "，" + age + " 岁，专业是 " + major);
    }

    void study(String course) {
        System.out.println(name + " 正在学习 " + course);
    }
}
```

```java
// 使用类：创建对象
public class StudentTest {
    public static void main(String[] args) {
        // 创建对象：类名 对象名 = new 类名();
        Student s1 = new Student();
        s1.name = "张三";
        s1.age = 20;
        s1.major = "计算机科学";

        Student s2 = new Student();
        s2.name = "李四";
        s2.age = 21;
        s2.major = "软件工程";

        s1.introduce();          // 我是 张三，20 岁，专业是 计算机科学
        s2.introduce();
        s1.study("Java 程序设计");
    }
}
```

**内存模型理解**：
- `new Student()` 在**堆内存**中创建对象。
- `s1`、`s2` 是**引用变量**，存放在栈中，指向堆中的对象。
- 每个对象拥有自己独立的属性副本。

## 2.2 构造方法

构造方法用于**创建对象时初始化属性**，特点：方法名与类名相同、无返回值、通过 `new` 调用。

```java
public class Person {
    String name;
    int age;

    // 无参构造方法（不写时 Java 会默认提供一个）
    public Person() {
        System.out.println("调用了无参构造方法");
    }

    // 有参构造方法（可以重载：方法名相同，参数列表不同）
    public Person(String name, int age) {
        this.name = name;   // this 指当前对象，用于区分成员变量与参数
        this.age = age;
        System.out.println("调用了带参构造方法");
    }

    void show() {
        System.out.println(name + "，" + age + " 岁");
    }

    public static void main(String[] args) {
        Person p1 = new Person();                    // 无参
        Person p2 = new Person("王五", 30);          // 带参
        p2.show();                                    // 王五，30 岁
    }
}
```

> 如果定义了带参构造方法，默认无参构造方法**不会自动生成**（想用需显式写出）。

## 2.3 封装（Encapsulation）

封装：将属性设为 `private`，通过 `public` 的 **getter/setter** 方法访问，隐藏内部实现细节。

```java
public class Account {
    // 私有属性：外部不能直接访问
    private String accountNo;
    private double balance;

    // 构造方法
    public Account(String accountNo, double balance) {
        this.accountNo = accountNo;
        this.balance = balance;
    }

    // getter / setter：提供受控的访问
    public String getAccountNo() {
        return accountNo;
    }

    public double getBalance() {
        return balance;
    }

    // 在 setter 中加入校验逻辑
    public void setBalance(double balance) {
        if (balance < 0) {
            System.out.println("余额不能为负数！");
            return;
        }
        this.balance = balance;
    }

    // 业务方法：存款
    public void deposit(double amount) {
        if (amount <= 0) {
            System.out.println("存款金额必须大于 0");
            return;
        }
        balance += amount;
        System.out.println("存入 " + amount + "，当前余额 " + balance);
    }

    // 业务方法：取款
    public void withdraw(double amount) {
        if (amount <= 0) {
            System.out.println("取款金额非法");
            return;
        }
        if (amount > balance) {
            System.out.println("余额不足，取款失败");
            return;
        }
        balance -= amount;
        System.out.println("取出 " + amount + "，当前余额 " + balance);
    }
}
```

```java
public class AccountTest {
    public static void main(String[] args) {
        Account acc = new Account("6222-0001", 1000);
        // acc.balance = -500;   // 错误！balance 是 private，无法直接访问

        acc.deposit(500);    // 存入 500，当前余额 1500
        acc.withdraw(2000);  // 余额不足，取款失败
        acc.withdraw(300);   // 取出 300，当前余额 1200
        System.out.println("当前余额：" + acc.getBalance());
    }
}
```

**封装的好处**：数据安全（可校验）、内部实现可自由修改、代码复用。

## 2.4 访问修饰符

| 修饰符 | 同类 | 同包 | 子类（不同包） | 任意位置 |
| --- | --- | --- | --- | --- |
| `private` | ✅ | ❌ | ❌ | ❌ |
| `default`（默认不写） | ✅ | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ | ✅ |

## 2.5 static 关键字

`static`（静态）：属于**类本身**，所有对象共享；通过**类名直接调用**，无需创建对象。

```java
public class StaticDemo {
    // 静态属性：所有实例共享同一份
    static int totalCount = 0;

    // 实例属性：每个对象各自一份
    String name;

    // 静态方法
    static void printCount() {
        System.out.println("当前总数为：" + totalCount);
        // System.out.println(name);  // 错误！静态方法不能直接访问实例属性
    }

    // 静态代码块：类加载时执行一次，常用于初始化
    static {
        System.out.println("静态代码块执行了");
        totalCount = 100;
    }

    public StaticDemo(String name) {
        this.name = name;
        totalCount++;
    }

    public static void main(String[] args) {
        StaticDemo.printCount();    // 类名.方法名 调用
        new StaticDemo("对象A");
        new StaticDemo("对象B");
        StaticDemo.printCount();    // 总数变为 102
    }
}
```

> 工具类（如 `Math`、`Arrays`）的方法通常都是 `static`，用 `Math.abs(-5)` 这种方式调用。

## 2.6 继承（Inheritance）

继承：子类（subclass）继承父类（superclass）的属性和方法，实现**代码复用**。Java 只支持**单继承**（一个类只能有一个直接父类），但支持多层继承。

```java
// 父类
public class Animal {
    protected String name;

    public Animal(String name) {
        this.name = name;
    }

    public void eat() {
        System.out.println(name + " 正在吃东西");
    }

    public void sleep() {
        System.out.println(name + " 在睡觉");
    }
}
```

```java
// 子类：Dog 继承 Animal，自动拥有 name、eat()、sleep()
public class Dog extends Animal {
    public Dog(String name) {
        super(name);   // super() 调用父类构造方法，必须放在第一行
    }

    // 方法重写（Override）：子类重新实现父类方法
    @Override
    public void eat() {
        System.out.println(name + " 在啃骨头");
    }

    // 子类自己的新方法
    public void bark() {
        System.out.println(name + " 汪汪叫");
    }
}
```

```java
public class InheritTest {
    public static void main(String[] args) {
        Dog dog = new Dog("旺财");
        dog.eat();     // 调用的是重写后的方法：旺财 在啃骨头
        dog.sleep();   // 继承自父类：旺财 在睡觉
        dog.bark();    // 子类特有：旺财 汪汪叫
    }
}
```

**重写规则**：方法名、参数列表必须相同；访问权限不能比父类更严格；`@Override` 注解用于校验。

## 2.7 多态（Polymorphism）

多态：**同一行为，不同实现**。前提：继承 + 方法重写 + 父类引用指向子类对象。

```java
public class Animal {
    protected String name;

    public Animal(String name) {
        this.name = name;
    }

    public void speak() {
        System.out.println("动物在叫");
    }
}

class Cat extends Animal {
    public Cat(String name) {
        super(name);
    }

    @Override
    public void speak() {
        System.out.println(name + " 喵喵叫");
    }
}

class Dog extends Animal {
    public Dog(String name) {
        super(name);
    }

    @Override
    public void speak() {
        System.out.println(name + " 汪汪叫");
    }
}
```

```java
public class PolymorphismDemo {
    public static void main(String[] args) {
        // 父类引用指向子类对象（向上转型）
        Animal a1 = new Cat("咪咪");
        Animal a2 = new Dog("旺财");

        // 编译看左边（Animal），运行看右边（实际对象）—— 动态绑定
        a1.speak();   // 咪咪 喵喵叫
        a2.speak();   // 旺财 汪汪叫

        // 多态的好处：写通用方法，传不同子类
        makeSound(a1);
        makeSound(a2);
        makeSound(new Animal("未知动物"));
    }

    // 一个方法，多种表现 —— 面向接口/父类编程
    public static void makeSound(Animal animal) {
        animal.speak();
    }
}
```

**向下转型**（需要时）：

```java
Animal a = new Cat("咪咪");
if (a instanceof Cat) {          // instanceof 判断对象真实类型
    Cat cat = (Cat) a;           // 向下转型，才能调用 Cat 特有方法
    cat.catchMouse();
}
```

## 2.8 抽象类（Abstract Class）

抽象类：**不能实例化**，用于定义子类的通用模板；包含抽象方法（只有声明，没有实现），由子类实现。

```java
// 抽象类
public abstract class Shape {
    protected String color;

    public Shape(String color) {
        this.color = color;
    }

    // 抽象方法：没有方法体，子类必须重写
    public abstract double area();

    // 具体方法：子类可以直接继承
    public void show() {
        System.out.println(color + "图形，面积 = " + area());
    }
}
```

```java
class Circle extends Shape {
    private double radius;

    public Circle(String color, double radius) {
        super(color);
        this.radius = radius;
    }

    @Override
    public double area() {
        return Math.PI * radius * radius;
    }
}

class Rectangle extends Shape {
    private double width, height;

    public Rectangle(String color, double width, double height) {
        super(color);
        this.width = width;
        this.height = height;
    }

    @Override
    public double area() {
        return width * height;
    }
}
```

```java
public class AbstractDemo {
    public static void main(String[] args) {
        // Shape s = new Shape("红色");  // 错误！抽象类不能实例化

        Shape c = new Circle("红色", 5);
        Shape r = new Rectangle("蓝色", 4, 6);

        c.show();   // 红色图形，面积 = 78.539...
        r.show();   // 蓝色图形，面积 = 24.0
    }
}
```

## 2.9 接口（Interface）

接口：**比抽象类更抽象**，定义规范（契约），不包含实现。类通过 `implements` 实现接口（可多实现）。

> JDK 8 之前接口只能有抽象方法；JDK 8+ 允许 `default` 方法（有默认实现）和 `static` 方法。

```java
// 接口：定义飞行能力规范
public interface Flyable {
    // 接口常量：隐式为 public static final
    int MAX_SPEED = 1000;

    // 抽象方法：隐式为 public abstract
    void fly();

    void land();

    // default 方法：可以有默认实现
    default void hover() {
        System.out.println("默认实现：悬停在空中");
    }

    // static 方法
    static void info() {
        System.out.println("这是一个飞行接口");
    }
}
```

```java
// 实现接口
class Bird implements Flyable {
    private String name;

    public Bird(String name) {
        this.name = name;
    }

    @Override
    public void fly() {
        System.out.println(name + " 扇动翅膀飞行");
    }

    @Override
    public void land() {
        System.out.println(name + " 降落在树枝上");
    }
}

class Plane implements Flyable {
    private String model;

    public Plane(String model) {
        this.model = model;
    }

    @Override
    public void fly() {
        System.out.println(model + " 发动机推进飞行");
    }

    @Override
    public void land() {
        System.out.println(model + " 降落在跑道上");
    }
}
```

```java
public class InterfaceDemo {
    public static void main(String[] args) {
        Flyable.info();                    // 静态方法：通过接口名调用

        Flyable bird = new Bird("麻雀");
        Flyable plane = new Plane("波音737");

        bird.fly();    // 麻雀 扇动翅膀飞行
        bird.land();   // 麻雀 降落在树枝上
        plane.fly();   // 波音737 发动机推进飞行
        plane.land();  // 波音737 降落在跑道上
        plane.hover(); // 默认实现：悬停在空中
    }
}
```

### 接口 vs 抽象类对比

| 对比项 | 抽象类 | 接口 |
| --- | --- | --- |
| 关键字 | `abstract class` | `interface` |
| 继承/实现 | `extends`（单继承） | `implements`（多实现） |
| 成员变量 | 任意 | 只能是常量 |
| 构造方法 | 有 | 没有 |
| 方法 | 抽象 + 具体 | 抽象 + default + static（JDK8+） |
| 语义 | "是什么"（is-a） | "能做什么"（can-do） |

## 2.10 Object 类与常用方法

所有类都隐式继承 `Object`，常用方法：

```java
public class ObjectMethodDemo {
    public static void main(String[] args) {
        // toString()：默认输出 "类名@哈希码"，建议重写
        Student s = new Student("张三", 20);
        System.out.println(s);          // 自动调用 toString()

        // equals()：默认比较地址，建议重写为按内容比较
        Student s1 = new Student("张三", 20);
        Student s2 = new Student("张三", 20);
        System.out.println(s1.equals(s2));   // 重写后为 true
        System.out.println(s1 == s2);        // false（== 比较地址）
    }
}

// 演示类：重写 toString 和 equals
class Student {
    String name;
    int age;

    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }

    @Override
    public String toString() {
        return "Student{name='" + name + "', age=" + age + "}";
    }

    @Override
    public boolean equals(Object obj) {
        if (this == obj) return true;
        if (obj == null || getClass() != obj.getClass()) return false;
        Student s = (Student) obj;
        return age == s.age && name.equals(s.name);
    }

    // 重写 equals 必须同时重写 hashCode（集合框架中会用到）
    @Override
    public int hashCode() {
        return 31 * age + (name == null ? 0 : name.hashCode());
    }
}
```
