# 第八章 发送邮件（JavaMail）

> 本章掌握：邮件协议基础、JavaMail API、发送纯文本/HTML/附件/图片邮件、批量与异步发送、封装邮件工具类。
> 邮件功能是几乎所有系统的标配（注册验证码、通知提醒、报表发送等）。

## 8.1 邮件协议基础

| 协议 | 全称 | 用途 | 默认端口 |
| --- | --- | --- | --- |
| SMTP | Simple Mail Transfer Protocol | **发送**邮件 | 25（明文）/ 465（SSL）/ 587（TLS） |
| POP3 | Post Office Protocol | **接收**邮件（下载后离线阅读） | 110 / 995（SSL） |
| IMAP | Internet Message Access Protocol | **接收**邮件（服务器同步管理） | 143 / 993（SSL） |

**工作原理**：

```
你的程序 ──SMTP──► 你的邮箱服务器(发件箱) ──SMTP──► 收件人邮箱服务器(收件箱) ──POP3/IMAP──► 收件人客户端
```

Java 程序只负责**通过 SMTP 把邮件交给自己的邮箱服务器**，投递过程由服务器完成。

### 8.2.2 获取邮箱 SMTP 授权码

以 **QQ 邮箱**为例（其他邮箱类似）：

1. 登录 QQ 邮箱网页版 → 设置 → 账号。
2. 找到 **POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务**。
3. 开启 **IMAP/SMTP 服务**。
4. 按提示用手机发送短信验证，获取**授权码**（16 位字母，**不是登录密码**）。

## 8.3 发送第一封邮件（纯文本）

```java
import javax.mail.*;
import javax.mail.internet.InternetAddress;
import javax.mail.internet.MimeMessage;
import java.util.Properties;

public class SendTextMail {
    // ===== 邮件服务器配置（修改为你自己的）=====
    private static final String SMTP_HOST = "smtp.qq.com";   // SMTP 服务器地址
    private static final String SMTP_PORT = "465";           // 端口（QQ 邮箱 465 SSL）
    private static final String FROM_EMAIL = "你的QQ号@qq.com"; // 发件人邮箱
    private static final String AUTH_CODE = "你的16位授权码";  // 授权码（不是QQ密码）

    public static void main(String[] args) {
        // 1. 配置邮件会话属性
        Properties props = new Properties();
        props.put("mail.smtp.host", SMTP_HOST);        // SMTP 服务器
        props.put("mail.smtp.port", SMTP_PORT);        // 端口
        props.put("mail.smtp.auth", "true");           // 需要认证
        props.put("mail.smtp.ssl.enable", "true");     // 启用 SSL 加密
        // props.put("mail.smtp.starttls.enable", "true"); // 使用 587 端口时开启 TLS

        // 2. 创建会话（携带认证信息）
        Session session = Session.getInstance(props, new Authenticator() {
            @Override
            protected PasswordAuthentication getPasswordAuthentication() {
                // 认证：邮箱账号 + 授权码
                return new PasswordAuthentication(FROM_EMAIL, AUTH_CODE);
            }
        });
        // session.setDebug(true);   // 打开调试日志，方便排查问题

        try {
            // 3. 创建邮件对象
            MimeMessage message = new MimeMessage(session);
            message.setFrom(new InternetAddress(FROM_EMAIL, "Java学习测试", "UTF-8"));  // 发件人（可带昵称）
            message.setRecipient(Message.RecipientType.TO,
                    new InternetAddress("收件人邮箱@qq.com", "张三", "UTF-8"));          // 收件人
            message.setSubject("第一封 Java 邮件", "UTF-8");                            // 主题
            message.setText("你好，这是一封由 Java 程序发送的邮件！", "UTF-8");           // 正文

            // 4. 发送
            Transport.send(message);
            System.out.println("邮件发送成功！");
        } catch (Exception e) {
            System.out.println("邮件发送失败：" + e.getMessage());
            e.printStackTrace();
        }
    }
}
```

**核心步骤总结**（4 步）：
1. `Properties` 配置 SMTP 服务器/端口/认证/加密。
2. `Session.getInstance(props, Authenticator)` 创建会话。
3. 构建 `MimeMessage`：发件人、收件人、主题、正文。
4. `Transport.send(message)` 发送。

```java
        // 3. HTML 正文（注意编码与 Content-Type）
        String html = "<!DOCTYPE html>"
                + "<html><head><meta charset='UTF-8'></head><body>"
                + "<h2 style='color:#2f6fed;'>尊敬的会员：</h2>"
                + "<p>欢迎注册 <b>Java 学习平台</b>！</p>"
                + "<p>您的注册验证码是：</p>"
                + "<p style='font-size:28px;font-weight:bold;color:#e4393c;letter-spacing:4px;'>"
                + "  <span style='border:1px solid #ccc;padding:6px 12px;'>4 8 2 6 9 1</span>"
                + "</p>"
                + "<p>验证码 5 分钟内有效，请勿泄露给他人。</p>"
                + "<hr>"
                + "<p style='color:#999;font-size:12px;'>此为系统邮件，请勿直接回复。</p>"
                + "</body></html>";

        // 关键：setContent 而不是 setText
        message.setContent(html, "text/html;charset=UTF-8");

        // 4. 发送
        Transport.send(message);
        System.out.println("HTML 邮件发送成功！");
    }
}
```

## 8.5 发送带附件的邮件

```java
import javax.activation.DataHandler;
import javax.activation.DataSource;
import javax.activation.FileDataSource;
import javax.mail.*;
import javax.mail.internet.InternetAddress;
import javax.mail.internet.MimeBodyPart;
import javax.mail.internet.MimeMessage;
import javax.mail.internet.MimeMultipart;

public class SendAttachmentMail {

    public static void main(String[] args) throws Exception {
        Session session = MailUtil.createSession();

        MimeMessage message = new MimeMessage(session);
        message.setFrom(new InternetAddress(MailUtil.FROM_EMAIL, "报表中心", "UTF-8"));
        message.setRecipient(Message.RecipientType.TO,
                new InternetAddress("收件人邮箱@qq.com"));
        message.setSubject("月度报表（含附件）", "UTF-8");

        // ===== 构建多部分邮件 =====

        // 1) 正文部分
        MimeBodyPart textPart = new MimeBodyPart();
        textPart.setContent("<h3>以下是本月销售报表，请查收。</h3>", "text/html;charset=UTF-8");

        // 2) 附件部分
        MimeBodyPart filePart = new MimeBodyPart();
        // 附件路径（请改为你电脑上的真实文件）
        String filePath = "d:/project/java/docs/java-learning/report.pdf";
        DataSource source = new FileDataSource(filePath);
        filePart.setDataHandler(new DataHandler(source));
        // 设置附件文件名（解决中文文件名乱码）
        filePart.setFileName(MimeUtility.encodeText("月度销售报表.pdf", "UTF-8", "B"));

        // 3) 组合：正文 + 附件
        MimeMultipart multipart = new MimeMultipart();
        multipart.addBodyPart(textPart);
        multipart.addBodyPart(filePart);

        // 4) 设置邮件内容为 multipart
        message.setContent(multipart);

        // 5) 发送
        Transport.send(message);
        System.out.println("附件邮件发送成功！");
    }
}
```

## 8.6 邮件中嵌入图片

```java
import javax.activation.DataHandler;
import javax.activation.DataSource;
import javax.activation.FileDataSource;
import javax.mail.*;
import javax.mail.internet.InternetAddress;
import javax.mail.internet.MimeBodyPart;
import javax.mail.internet.MimeMessage;
import javax.mail.internet.MimeMultipart;

public class SendImageMail {

    public static void main(String[] args) throws Exception {
        Session session = MailUtil.createSession();

        MimeMessage message = new MimeMessage(session);
        message.setFrom(new InternetAddress(MailUtil.FROM_EMAIL, "活动中心", "UTF-8"));
        message.setRecipient(Message.RecipientType.TO,
                new InternetAddress("收件人邮箱@qq.com"));
        message.setSubject("限时促销活动", "UTF-8");

        // ===== 构建：文本 + 内嵌图片 =====

        // 1) 正文部分（用 <img src="cid:图片ID"> 引用内嵌图片）
        MimeBodyPart textPart = new MimeBodyPart();
        String html = "<h3>年中大促，全场 5 折起！</h3>"
                + "<img src='cid:saleBanner' width='480'>";   // cid 与下面的 Content-ID 对应
        textPart.setContent(html, "text/html;charset=UTF-8");

        // 2) 内嵌图片部分（related，不是附件）
        MimeBodyPart imagePart = new MimeBodyPart();
        String imgPath = "d:/project/java/docs/java-learning/banner.png";  // 本地图片路径
        DataSource ds = new FileDataSource(imgPath);
        imagePart.setDataHandler(new DataHandler(ds));
        imagePart.setHeader("Content-ID", "<saleBanner>");   // 必须与 cid 一致
        imagePart.setDisposition(MimeBodyPart.INLINE);       // 内嵌显示

        // 3) 组合（MULTIPART/related 类型）
        MimeMultipart multipart = new MimeMultipart("related");
        multipart.addBodyPart(textPart);
        multipart.addBodyPart(imagePart);

        message.setContent(multipart);
        Transport.send(message);
        System.out.println("图文邮件发送成功！");
    }
}
```

## 8.7 封装邮件工具类（生产可用）

把配置和常用发送逻辑封装成工具类，业务代码只需一行调用：

```java
import javax.activation.DataHandler;
import javax.activation.DataSource;
import javax.activation.FileDataSource;
import javax.mail.*;
import javax.mail.internet.*;
import java.util.List;
import java.util.Properties;

/**
 * 邮件发送工具类
 * 支持：文本 / HTML / 附件 / 内嵌图片 / 群发
 */
public class MailUtil {
    // ===== 基础配置（按需修改）=====
    private static final String SMTP_HOST = "smtp.qq.com";
    private static final String SMTP_PORT = "465";
    public static final String FROM_EMAIL = "你的QQ号@qq.com";
    private static final String AUTH_CODE = "你的16位授权码";

    // 创建 Session（单例模式，避免重复创建）
    private static volatile Session session;

    public static Session createSession() {
        if (session == null) {
            synchronized (MailUtil.class) {
                if (session == null) {
                    Properties props = new Properties();
                    props.put("mail.smtp.host", SMTP_HOST);
                    props.put("mail.smtp.port", SMTP_PORT);
                    props.put("mail.smtp.auth", "true");
                    props.put("mail.smtp.ssl.enable", "true");
                    props.put("mail.smtp.connectiontimeout", "10000");   // 连接超时 10 秒
                    props.put("mail.smtp.timeout", "15000");             // 读取超时 15 秒
                    props.put("mail.smtp.writetimeout", "15000");        // 写入超时 15 秒

                    session = Session.getInstance(props, new Authenticator() {
                        @Override
                        protected PasswordAuthentication getPasswordAuthentication() {
                            return new PasswordAuthentication(FROM_EMAIL, AUTH_CODE);
                        }
                    });
                }
            }
        }
        return session;
    }

    // ===== 发送纯文本邮件 =====
    public static void sendTextMail(String to, String subject, String content) throws MessagingException {
        MimeMessage message = new MimeMessage(createSession());
        message.setFrom(new InternetAddress(FROM_EMAIL, "系统通知", "UTF-8"));
        message.setRecipient(Message.RecipientType.TO, new InternetAddress(to));
        message.setSubject(subject, "UTF-8");
        message.setText(content, "UTF-8");
        Transport.send(message);
    }

    // ===== 发送 HTML 邮件 =====
    public static void sendHtmlMail(String to, String subject, String htmlContent) throws MessagingException {
        MimeMessage message = new MimeMessage(createSession());
        message.setFrom(new InternetAddress(FROM_EMAIL, "系统通知", "UTF-8"));
        message.setRecipient(Message.RecipientType.TO, new InternetAddress(to));
        message.setSubject(subject, "UTF-8");
        message.setContent(htmlContent, "text/html;charset=UTF-8");
        Transport.send(message);
    }

    // ===== 发送带附件的邮件 =====
    public static void sendAttachmentMail(String to, String subject, String content,
                                          List<String> attachmentPaths) throws Exception {
        MimeMessage message = new MimeMessage(createSession());
        message.setFrom(new InternetAddress(FROM_EMAIL, "系统通知", "UTF-8"));
        message.setRecipient(Message.RecipientType.TO, new InternetAddress(to));
        message.setSubject(subject, "UTF-8");

        // 正文
        MimeBodyPart textPart = new MimeBodyPart();
        textPart.setContent(content, "text/html;charset=UTF-8");

        MimeMultipart multipart = new MimeMultipart();
        multipart.addBodyPart(textPart);

        // 多个附件
        for (String path : attachmentPaths) {
            MimeBodyPart filePart = new MimeBodyPart();
            DataSource source = new FileDataSource(path);
            filePart.setDataHandler(new DataHandler(source));
            filePart.setFileName(MimeUtility.encodeText(
                    new java.io.File(path).getName(), "UTF-8", "B"));
            multipart.addBodyPart(filePart);
        }

        message.setContent(multipart);
        Transport.send(message);
    }

    // ===== 群发邮件（多个收件人）=====
    public static void sendMailToMany(List<String> recipients, String subject,
                                      String htmlContent) throws MessagingException {
        MimeMessage message = new MimeMessage(createSession());
        message.setFrom(new InternetAddress(FROM_EMAIL, "系统通知", "UTF-8"));

        // 添加多个收件人
        for (String to : recipients) {
            message.addRecipient(Message.RecipientType.TO, new InternetAddress(to));
        }

        message.setSubject(subject, "UTF-8");
        message.setContent(htmlContent, "text/html;charset=UTF-8");
        Transport.send(message);
    }
}
```

## 8.8 异步发送邮件（线程池 + 队列）

发邮件是 IO 操作，**耗时较长**（1~3 秒），如果在用户请求中同步执行会阻塞响应。生产环境通常**异步发送**。

### 8.8.1 简单异步发送（线程池）

```java
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.ThreadFactory;
import java.util.concurrent.atomic.AtomicInteger;

public class AsyncMailSender {
    // 线程池：核心 2、最大 4、队列 100（发邮件是 IO 密集，线程不宜太多）
    private static final ExecutorService POOL = Executors.newFixedThreadPool(
            4, new ThreadFactory() {
                private final AtomicInteger n = new AtomicInteger(1);

                @Override
                public Thread newThread(Runnable r) {
                    Thread t = new Thread(r, "mail-sender-" + n.getAndIncrement());
                    t.setDaemon(true);   // 守护线程：主程序退出时不阻塞
                    return t;
                }
            });

    /**
     * 异步发送 HTML 邮件
     * @return true 表示已提交到队列（不代表发送成功）
     */
    public static boolean sendAsync(String to, String subject, String html) {
        try {
            POOL.submit(() -> {
                try {
                    MailUtil.sendHtmlMail(to, subject, html);
                    System.out.println("[" + Thread.currentThread().getName() + "] 邮件发送成功 -> " + to);
                } catch (Exception e) {
                    System.out.println("邮件发送失败 -> " + to + "：" + e.getMessage());
                }
            });
            return true;
        } catch (Exception e) {
            System.out.println("任务提交失败：" + e.getMessage());
            return false;
        }
    }

    public static void main(String[] args) {
        // 模拟批量通知：立即返回，后台慢慢发送
        for (int i = 1; i <= 10; i++) {
            sendAsync("user" + i + "@qq.com", "批量通知-" + i,
                    "<p>这是第 " + i + " 条通知。</p>");
        }
        System.out.println("所有邮件任务已提交（异步发送中）...");
        // 生产环境注意：进程退出前需要优雅关闭线程池
        // POOL.shutdown();
    }
}
```

### 8.8.2 批量发送场景：给 1000 个用户发验证码

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Random;

public class BatchSendDemo {
    public static void main(String[] args) {
        // 模拟 1000 个用户邮箱
        List<String> emails = new ArrayList<>();
        for (int i = 1; i <= 1000; i++) {
            emails.add("user" + i + "@example.com");
        }

        long start = System.currentTimeMillis();

        // 方案一（错误示范）：同步逐条发送，1000 条需要 1000 × 2 秒 ≈ 33 分钟
        // for (String email : emails) {
        //     MailUtil.sendHtmlMail(email, "验证码", buildCodeHtml(genCode()));
        // }

        // 方案二（推荐）：分批并行发送
        // 每批 50 条，交给异步线程池（示例仅演示分批逻辑）
        int batchSize = 50;
        List<List<String>> batches = partition(emails, batchSize);
        for (List<String> batch : batches) {
            for (String email : batch) {
                AsyncMailSender.sendAsync(email, "注册验证码", buildCodeHtml(genCode()));
            }
        }

        System.out.println("提交完成，1000 封邮件已进入发送队列，耗时："
                + (System.currentTimeMillis() - start) + "ms");
    }

    // 生成 6 位随机验证码
    private static String genCode() {
        return String.format("%06d", new Random().nextInt(1000000));
    }

    // 生成验证码 HTML
    private static String buildCodeHtml(String code) {
        return "<p>您的验证码是：<b style='color:#e4393c;font-size:22px;'>" + code + "</b></p>";
    }

    // 列表分批
    private static List<List<String>> partition(List<String> list, int size) {
        List<List<String>> result = new ArrayList<>();
        for (int i = 0; i < list.size(); i += size) {
            result.add(list.subList(i, Math.min(i + size, list.size())));
        }
        return result;
    }
}
```

## 8.9 常见问题排查

| 报错 / 现象 | 原因 | 解决办法 |
| --- | --- | --- |
| `AuthenticationFailedException` | 授权码错误或未开启 SMTP 服务 | 检查授权码是否正确、确认已开启 SMTP 服务 |
| `Could not connect to SMTP host` | 网络不通或端口被墙 | 检查服务器地址、端口、防火墙；部分网络需开 SSL |
| `Unsupported response / 535 Error` | 使用了 QQ 密码而非授权码 | 登录邮箱设置获取**授权码** |
| 中文主题乱码 | 未设置编码 | `setSubject("主题", "UTF-8")` |
| 附件中文名乱码 | 未编码附件名 | `setFileName(MimeUtility.encodeText(文件名, "UTF-8", "B"))` |
| 发送成功但收不到 | 被对方邮箱拦截为垃圾邮件 | 检查收件箱/垃圾箱；降低推广内容敏感词 |
| 发送超时 | 网络慢 / 服务器繁忙 | 配置 `mail.smtp.connectiontimeout` 等超时参数 |
| 垃圾邮件标记 | 发件人信誉低 | 使用专业邮件服务商（SendGrid、阿里云邮件推送等） |

### 代码中的常见坑

```java
// ❌ 错误：setText 会按纯文本发送，HTML 标签原样显示
message.setText("<h1>标题</h1>");

// ✅ 正确：必须用 setContent 并指定 text/html
message.setContent("<h1>标题</h1>", "text/html;charset=UTF-8");
```

```java
// ❌ 错误：setRecipient 多次调用会互相覆盖
message.setRecipient(Message.RecipientType.TO, addr1);
message.setRecipient(Message.RecipientType.TO, addr2);   // 覆盖了 addr1

// ✅ 正确：群发用 addRecipient（追加）
message.addRecipient(Message.RecipientType.TO, addr1);
message.addRecipient(Message.RecipientType.TO, addr2);
```

```java
// ❌ 错误：把授权码硬编码提交到 Git 仓库（安全风险）
String AUTH_CODE = "xxxxxxxx";

// ✅ 正确：从环境变量 / 配置文件读取
String AUTH_CODE = System.getenv("MAIL_AUTH_CODE");
```

## 8.10 生产环境方案对比

| 方案 | 适用场景 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 直接 SMTP（本教程） | 学习、小型应用 | 零成本、简单 | 易进垃圾箱、投递率不稳定 |
| 邮件推送服务（阿里云/腾讯云） | 国内企业应用 | 投递率高、有统计 | 收费 |
| SendGrid / Mailgun | 海外应用 | 高投递率、API 完善 | 需要外网 |
| Spring Boot `spring-boot-starter-mail` | Spring 项目 | 配置简单、整合方便 | 依赖 Spring |

> 提示：Spring Boot 项目中可配置 `spring.mail.*` 属性，注入 `JavaMailSender` 使用，底层封装的就是 JavaMail。
