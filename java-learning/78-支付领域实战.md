## 78.1 支付领域的边界与"资金不变量"

### 78.1.1 支付上下文负责

- 用户账户余额管理（充值/冻结/扣款）
- 资金操作幂等（基于 idempotency_key）
- 与外部支付通道的防腐层集成
- 资金事件发布（与订单/库存 Saga 协调）

### 78.1.2 资金不变量（**绝对不可违反**）

| 不变量 | 描述 | 实现位置 |
| --- | --- | --- |
| 余额非负 | `balance ≥ 0` | 领域层 + DB CHECK |
| 冻结非负 | `frozen ≥ 0` | 领域层 + DB CHECK |
| 总额守恒 | `balance + frozen = 总额` | 领域层 |
| 操作幂等 | 同 idempotency_key 多次调用结果一致 | 仓储层唯一约束 |

## 78.2 账户聚合（Account）：余额 + 状态 + 历史

### 78.2.1 完整 Account 聚合根

```java
public class Account {

    private final Long id;
    private final Long userId;
    private BigDecimal balance;
    private BigDecimal frozen;
    private final String currency;
    private long version;                       // 乐观锁
    private Instant updatedAt;

    /** 工厂方法：新开账户。 */
    public static Account open(Long userId, String currency) {
        return new Account(null, userId, BigDecimal.ZERO, currency, 0, Instant.now());
    }

    /** 仓储层重建（含 version）。 */
    public Account(Long id, Long userId, BigDecimal balance,
                   String currency, long version, Instant updatedAt) {
        requirePositive(balance, "余额");
        requirePositive(frozen(), "冻结金额");      // 注：构造器中 frozen 还没赋值
        if (balance.signum() < 0) {
            throw new IllegalArgumentException("初始余额不能为负");
        }
        this.id = id;
        this.userId = userId;
        this.balance = balance;
        this.frozen = BigDecimal.ZERO;
        this.currency = currency;
        this.version = version;
        this.updatedAt = updatedAt;
    }

    // 注：上面构造器参数顺序已简化（实际应为 id, userId, balance, currency, version, updatedAt）。
    // 真实代码参见 examples/03-ecommerce-order/payment 包内 Account.java。

    // ===== 行为方法 =====

    /** 充值：增加可用余额。 */
    public void deposit(BigDecimal amount) {
        requirePositive(amount, "充值金额");
        this.balance = this.balance.add(amount);
        this.updatedAt = Instant.now();
    }

    /** 冻结：balance → frozen（用于下单"预扣"）。 */
    public void freeze(BigDecimal amount) {
        requirePositive(amount, "冻结金额");
        if (this.balance.compareTo(amount) < 0) {
            throw new InsufficientBalanceException(userId, balance, amount);
        }
        this.balance = this.balance.subtract(amount);
        this.frozen = this.frozen.add(amount);
        this.updatedAt = Instant.now();
    }

    /** 解冻：frozen → balance（订单取消时）。 */
    public void unfreeze(BigDecimal amount) {
        requirePositive(amount, "解冻金额");
        if (this.frozen.compareTo(amount) < 0) {
            throw new IllegalStateException("冻结金额不足：" + frozen + " < " + amount);
        }
        this.frozen = this.frozen.subtract(amount);
        this.balance = this.balance.add(amount);
        this.updatedAt = Instant.now();
    }

    /** 扣款：frozen 直接扣减（订单付款确认后）。 */
    public void deduct(BigDecimal amount) {
        requirePositive(amount, "扣款金额");
        if (this.frozen.compareTo(amount) < 0) {
            throw new IllegalStateException("冻结金额不足：" + frozen + " < " + amount);
        }
        this.frozen = this.frozen.subtract(amount);
        this.updatedAt = Instant.now();
    }

    private void requirePositive(BigDecimal amount, String label) {
        if (amount == null || amount.signum() <= 0) {
            throw new IllegalArgumentException(label + "必须为正：" + amount);
        }
    }

    // ===== Getter =====

    public Long id() { return id; }
    public Long userId() { return userId; }
    public BigDecimal balance() { return balance; }
    public BigDecimal frozen() { return frozen; }
    public String currency() { return currency; }
    public long version() { return version; }
    public Instant updatedAt() { return updatedAt; }

    /** 余额不足异常。 */
    public static class InsufficientBalanceException extends RuntimeException {
        private final Long userId;
        private final BigDecimal balance;
        private final BigDecimal requested;

        public InsufficientBalanceException(Long userId, BigDecimal balance, BigDecimal requested) {
            super("余额不足：userId=" + userId + " 可用 " + balance + " 需要 " + requested);
            this.userId = userId;
            this.balance = balance;
            this.requested = requested;
        }

        public Long userId() { return userId; }
        public BigDecimal balance() { return balance; }
        public BigDecimal requested() { return requested; }
    }
}
```

> 上面构造器签名有冗余代码（实际生产代码会整理为单一构造器）。读者可对照 `examples/03` 的 Account.java 看最终版本。

## 78.3 资金操作幂等：基于幂等键（Idempotency Key）

### 78.3.1 什么是幂等？

> **同一笔资金操作，无论调用多少次，最终结果一致。**

例：

- 用户点击"支付"按钮 3 次，只扣一次款
- 网络重试导致 5 次"冻结"调用，最终只冻结一次

### 78.3.2 幂等键设计

```java
public record IdempotencyKey(String value) {
    public IdempotencyKey {
        if (value == null || value.isBlank()) {
            throw new IllegalArgumentException("幂等键不能为空");
        }
    }

    public static IdempotencyKey of(String value) {
        return new IdempotencyKey(value);
    }

    public static IdempotencyKey generate() {
        return new IdempotencyKey(UUID.randomUUID().toString());
    }
}
```

调用方在请求中带幂等键：

```java
public record FreezeCommand(
    Long userId,
    Money amount,
    IdempotencyKey idempotencyKey,    // 必填
    String businessOrderId
) {}
```

### 78.3.3 幂等键实现（仓储层唯一约束）

```sql
CREATE TABLE t_payment_operation (
    id                BIGINT       NOT NULL AUTO_INCREMENT,
    idempotency_key   VARCHAR(64)  NOT NULL,
    user_id           BIGINT       NOT NULL,
    operation_type    VARCHAR(16)  NOT NULL,    -- FREEZE / DEDUCT / UNFREEZE
    amount            DECIMAL(18, 2) NOT NULL,
    status            VARCHAR(16)  NOT NULL,    -- PENDING / SUCCESS / FAILED
    business_order_id VARCHAR(64)  NOT NULL,
    created_at        TIMESTAMP    NOT NULL,
    PRIMARY KEY (id),
    UNIQUE KEY uk_idempotency_key (idempotency_key)    -- 关键：唯一约束
);
```

```java
@Repository
public class MybatisPaymentOperationRepository {

    private final PaymentOperationMapper mapper;

    /** 保存幂等记录；重复时抛唯一约束异常。 */
    public void save(PaymentOperation op) {
        try {
            mapper.insert(toPO(op));
        } catch (DuplicateKeyException e) {
            throw new IdempotencyKeyConflictException(op.idempotencyKey());
        }
    }
}
```

### 78.3.4 应用层幂等处理

```java
@Service
public class PaymentAppService {

    private final AccountRepository accountRepository;
    private final PaymentOperationRepository operationRepository;

    @Transactional
    public String freeze(FreezeCommand cmd) {
        // 1. 先检查幂等键
        Optional<PaymentOperation> existing =
            operationRepository.findByIdempotencyKey(cmd.idempotencyKey());
        if (existing.isPresent() && existing.get().isSuccess()) {
            return existing.get().transactionId();   // 返回上次结果
        }

        // 2. 加载账户
        Account account = accountRepository.findByUserId(cmd.userId())
            .orElseThrow(() -> new AccountNotFoundException(cmd.userId()));

        // 3. 业务操作
        account.freeze(cmd.amount().amount());
        accountRepository.save(account);

        // 4. 记录幂等结果
        String transactionId = generateTransactionId();
        operationRepository.save(new PaymentOperation(
            null, cmd.idempotencyKey(), cmd.userId(),
            OperationType.FREEZE, cmd.amount().amount(),
            Status.SUCCESS, transactionId, cmd.businessOrderId(),
            Instant.now()
        ));

        return transactionId;
    }
}
```

## 78.4 Saga 入口：PaymentAppService.startPayment() 启动 Saga

### 78.4.1 Saga 启动入口

```java
@Service
public class PaymentAppService {

    private final AccountRepository accountRepository;
    private final SagaManager sagaManager;

    /**
     * Saga 入口：启动"下单-库存-支付"完整 Saga。
     *
     * <p>调用时机：订单创建完成后，由 OrderAppService 调用。
     */
    public String startPaymentSaga(StartPaymentSagaCommand cmd) {
        // 1. 冻结用户金额
        String transactionId = freeze(new FreezeCommand(
            cmd.userId(), cmd.amount(),
            IdempotencyKey.generate(), cmd.orderId().toString()
        ));

        // 2. 启动 Saga
        SagaInstance saga = sagaManager.start(new PaymentSaga(
            cmd.orderId(), cmd.userId(), cmd.amount(), transactionId
        ));

        return saga.id();
    }
}
```

### 78.4.2 PaymentSaga 定义（Saga 协调者）

```java
public class PaymentSaga implements SagaDefinition {

    private final Long orderId;
    private final Long userId;
    private final Money amount;
    private final String freezeTransactionId;

    /** Saga 步骤：冻结 → 扣款 → 完成。 */
    @Override
    public List<SagaStep> steps() {
        return List.of(
            // 步骤 1：冻结（已通过 freeze() 完成）
            new SagaStep("frozen", this::verifyFrozen, this::compensateUnfreeze),

            // 步骤 2：扣款
            new SagaStep("deduct", this::deduct, this::compensateUnfreeze),

            // 步骤 3：完成
            new SagaStep("completed", this::markCompleted, this::noCompensation)
        );
    }

    private boolean verifyFrozen(SagaContext ctx) {
        // 验证冻结是否成功（已经 freeze() 返回 transactionId，默认成功）
        return true;
    }

    private boolean deduct(SagaContext ctx) {
        // 调用 deduct() 完成扣款
        paymentAppService.deduct(userId, amount.amount(), freezeTransactionId);
        return true;
    }

    private boolean markCompleted(SagaContext ctx) {
        // 标记 Saga 完成
        return true;
    }

    private void compensateUnfreeze(SagaContext ctx) {
        // 补偿：解冻
        paymentAppService.unfreeze(userId, amount.amount(), freezeTransactionId);
    }

    private void noCompensation(SagaContext ctx) {
        // 终态无需补偿
    }
}
```

## 78.5 转账聚合（Transfer）：发起方 + 接收方 + 中间态

```java
public class Transfer {

    private final TransferId id;
    private final Long fromUserId;
    private final Long toUserId;
    private final Money amount;
    private TransferStatus status;
    private final Instant createdAt;
    private Instant completedAt;

    public Transfer(TransferId id, Long fromUserId, Long toUserId,
                    Money amount, Instant createdAt) {
        if (fromUserId.equals(toUserId)) {
            throw new IllegalArgumentException("转账双方不能相同");
        }
        this.id = id;
        this.fromUserId = fromUserId;
        this.toUserId = toUserId;
        this.amount = amount;
        this.createdAt = createdAt;
        this.status = TransferStatus.PENDING;
    }

    /** 成功完成。 */
    public void complete() {
        enforceStatus(TransferStatus.PENDING, "完成");
        this.status = TransferStatus.SUCCESS;
        this.completedAt = Instant.now();
    }

    /** 失败回滚。 */
    public void fail(String reason) {
        if (status == TransferStatus.SUCCESS) {
            throw new IllegalStateException("已成功转账不能失败");
        }
        this.status = TransferStatus.FAILED;
        this.completedAt = Instant.now();
    }

    private void enforceStatus(TransferStatus expected, String action) {
        if (status != expected) {
            throw new IllegalStateException("当前状态" + status + "不允许" + action);
        }
    }

    public enum TransferStatus { PENDING, SUCCESS, FAILED }

    // Getter 略
}
```

## 78.6 实战：账户 + 转账完整实现

### 78.6.1 账户应用服务（精简）

```java
@Service
public class PaymentAppService {

    private final AccountRepository accountRepository;
    private final PaymentOperationRepository operationRepository;

    /** 初始化账户。 */
    @Transactional
    public void openAccount(Long userId) {
        if (accountRepository.findByUserId(userId).isPresent()) {
            throw new BusinessException("ACCOUNT_EXISTS", "账户已存在");
        }
        accountRepository.save(Account.open(userId, "CNY"));
    }

    /** 充值（幂等）。 */
    @Transactional
    public void deposit(DepositCommand cmd) {
        // 幂等检查
        if (operationRepository.findByIdempotencyKey(cmd.idempotencyKey()).isPresent()) return;

        Account account = accountRepository.findByUserId(cmd.userId())
            .orElseThrow(() -> new AccountNotFoundException(cmd.userId()));
        account.deposit(cmd.amount().amount());
        accountRepository.save(account);

        operationRepository.save(new PaymentOperation(
            null, cmd.idempotencyKey(), cmd.userId(),
            OperationType.DEPOSIT, cmd.amount().amount(),
            Status.SUCCESS, null, null, Instant.now()
        ));
    }

    /** 冻结（幂等）。 */
    @Transactional
    public String freeze(FreezeCommand cmd) {
        // 幂等检查（见 78.3.4）
        Optional<PaymentOperation> existing =
            operationRepository.findByIdempotencyKey(cmd.idempotencyKey());
        if (existing.isPresent() && existing.get().isSuccess()) {
            return existing.get().transactionId();
        }

        Account account = accountRepository.findByUserId(cmd.userId())
            .orElseThrow(() -> new AccountNotFoundException(cmd.userId()));
        account.freeze(cmd.amount().amount());
        accountRepository.save(account);

        String transactionId = generateTransactionId();
        operationRepository.save(new PaymentOperation(
            null, cmd.idempotencyKey(), cmd.userId(),
            OperationType.FREEZE, cmd.amount().amount(),
            Status.SUCCESS, transactionId, cmd.businessOrderId(),
            Instant.now()
        ));

        return transactionId;
    }

    /** 解冻（幂等）。 */
    @Transactional
    public void unfreeze(Long userId, BigDecimal amount, String transactionId) {
        IdempotencyKey key = IdempotencyKey.of("unfreeze_" + transactionId);
        if (operationRepository.findByIdempotencyKey(key).isPresent()) return;

        Account account = accountRepository.findByUserId(userId).orElseThrow();
        account.unfreeze(amount);
        accountRepository.save(account);

        operationRepository.save(new PaymentOperation(
            null, key, userId, OperationType.UNFREEZE, amount,
            Status.SUCCESS, transactionId, null, Instant.now()
        ));
    }

    /** 扣款（幂等）。 */
    @Transactional
    public void deduct(Long userId, BigDecimal amount, String transactionId) {
        IdempotencyKey key = IdempotencyKey.of("deduct_" + transactionId);
        if (operationRepository.findByIdempotencyKey(key).isPresent()) return;

        Account account = accountRepository.findByUserId(userId).orElseThrow();
        account.deduct(amount);
        accountRepository.save(account);

        operationRepository.save(new PaymentOperation(
            null, key, userId, OperationType.DEDUCT, amount,
            Status.SUCCESS, transactionId, null, Instant.now()
        ));
    }

    private String generateTransactionId() {
        return "T" + System.currentTimeMillis() + UUID.randomUUID().toString().substring(0, 6).toUpperCase();
    }
}
```

## 78.7 与订单的协作：Saga 步骤 1「冻结」+ 步骤 2「确认扣款」

订单上下文 → 支付上下文的 Saga 编排：

```
[订单创建] ──► [调用 InventoryPort.reserve] ──► [发布 OrderCreatedEvent]
                                                        │
                                                        ▼
[异步 Saga] ──► [调用 PaymentPort.freeze] ──► [等待 OrderPaidEvent]
                                                        │
                                                        ▼
[收到 OrderPaidEvent] ──► [调用 PaymentPort.deduct] ──► [完成]
```

具体步骤（详见第 79 章跨上下文集成）：

1. **订单创建** → 同步调用 `InventoryPort.reserve`（强一致）
2. **订单创建后** → 异步调用 `PaymentPort.freeze`（Saga 步骤 1）
3. **订单付款** → 异步调用 `PaymentPort.deduct`（Saga 步骤 2）
4. **订单取消** → 异步调用 `PaymentPort.unfreeze`（Saga 补偿）

## 78.8 单元测试：幂等性测试 + 余额不足测试

```java
class AccountTest {

    @Test
    void should_deposit_increase_balance() {
        Account account = new Account(null, 1L, BigDecimal.ZERO, "CNY", 0, Instant.now());
        account.deposit(new BigDecimal("100"));
        assertEquals(new BigDecimal("100.00"), account.balance());
        assertEquals(BigDecimal.ZERO, account.frozen());
    }

    @Test
    void should_freeze_move_balance_to_frozen() {
        Account account = new Account(null, 1L, new BigDecimal("100"), "CNY", 0, Instant.now());
        account.freeze(new BigDecimal("30"));
        assertEquals(new BigDecimal("70.00"), account.balance());
        assertEquals(new BigDecimal("30.00"), account.frozen());
    }

    @Test
    void should_reject_freeze_when_insufficient_balance() {
        Account account = new Account(null, 1L, new BigDecimal("10"), "CNY", 0, Instant.now());
        assertThrows(Account.InsufficientBalanceException.class,
            () -> account.freeze(new BigDecimal("100")));
    }

    @Test
    void should_reject_negative_amount() {
        Account account = new Account(null, 1L, new BigDecimal("100"), "CNY", 0, Instant.now());
        assertThrows(IllegalArgumentException.class,
            () -> account.deposit(new BigDecimal("-1")));
    }

    @Test
    void should_unfreeze_recover_balance() {
        Account account = new Account(null, 1L, new BigDecimal("100"), "CNY", 0, Instant.now());
        account.freeze(new BigDecimal("30"));
        account.unfreeze(new BigDecimal("20"));
        assertEquals(new BigDecimal("90.00"), account.balance());
        assertEquals(new BigDecimal("10.00"), account.frozen());
    }

    @Test
    void should_deduct_reduce_frozen() {
        Account account = new Account(null, 1L, new BigDecimal("100"), "CNY", 0, Instant.now());
        account.freeze(new BigDecimal("50"));
        account.deduct(new BigDecimal("30"));
        assertEquals(new BigDecimal("50.00"), account.balance());
        assertEquals(new BigDecimal("20.00"), account.frozen());
    }
}
```

### 本章小结

- 支付领域 4 个不变量：余额非负 / 冻结非负 / 总额守恒 / 操作幂等。
- Account 聚合根 4 个行为：deposit / freeze / unfreeze / deduct。
- 幂等键设计：基于 idempotency_key 唯一约束 + 应用层检查。
- Saga 启动入口 PaymentAppService.startPayment() 协调订单-库存-支付。
- Transfer 聚合根实现"发起方 + 接收方 + 中间态"模型。
