## 3.1 纹理坐标：给每个顶点一张“寻址地图”

上章我们是**逐顶点给颜色**。真实世界里物体表面细节用**贴图（纹理）**提供：给每个顶点一个 `(u, v)` 坐标，GPU 光栅化时按三角形内插值出的 uv，去“图里取样”得到该像素颜色。

```text
  纹理坐标约定（OpenGL）         一张纹理
  (0,1) ──────── (1,1)        ┌──────────┐
    │   y↑（v 向上）           │  v=1     │
    │   │                      │   取点…  │
    │   └──→ x（u 向右）        │          │
  (0,0) ──────── (1,0)        └──────────┘
      纹理坐标永远归一化到 0~1
```

- 纹理坐标也叫 **uv**；`u` 对应纹理横向、`v` 对应纵向；
- 图片文件的第 0 行通常在顶部，而 OpenGL 的 v=0 在底部 → 加载图片通常需要**上下翻转**（3.4 节细讲）；
- 上章顶点数据里只存了 `位置+颜色`，本章变成 `位置+纹理坐标`（颜色交给纹理）。

## 3.2 纹理对象：创建、绑定、参数、上传

流程与 VBO 高度相似（生成-绑定-传数据），但多了**采样参数**：

```cpp
unsigned int texture;
glGenTextures(1, &texture);
glBindTexture(GL_TEXTURE_2D, texture);

// ① 采样参数（必设，否则纹理“不完整”会显示为白/黑）
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_REPEAT);   // u 方向超出怎么处理
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_T, GL_REPEAT);   // v 方向
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_LINEAR_MIPMAP_LINEAR);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_LINEAR);

// ② 上传像素：宽、高、内部格式、外部格式、数据类型、数据指针
glTexImage2D(GL_TEXTURE_2D, 0, GL_RGB, width, height, 0,
             GL_RGB, GL_UNSIGNED_BYTE, pixels);
glGenerateMipmap(GL_TEXTURE_2D);   // 为“缩小显示”生成多级纹理（防闪烁）
```

| 参数 | 值 | 含义 |
| --- | --- | --- |
| `GL_TEXTURE_WRAP_S/T` | `GL_REPEAT` / `GL_MIRRORED_REPEAT` / `GL_CLAMP_TO_EDGE` | 采样超出 [0,1] 时：重复平铺 / 镜像平铺 / 边缘拉伸 |
| `GL_TEXTURE_MIN_FILTER` | `GL_LINEAR` / `GL_NEAREST` / `GL_LINEAR_MIPMAP_*` | 纹理被**缩小**时（远处物体）怎么过滤 |
| `GL_TEXTURE_MAG_FILTER` | `GL_LINEAR`（双线性插值，平滑）/ `GL_NEAREST`（像素风） | 纹理被**放大**时怎么过滤 |

- **mipmap（多级纹理）**：预先为纹理生成从 1/1 到 1/最小的一系列缩小版本，采样远处像素时用更小的层级，避免“摩尔纹/闪烁”；
- `GL_LINEAR` vs `GL_NEAREST` 是图形风格分水岭：前者平滑，后者是 Minecraft/像素游戏的方块感。

## 3.3 动手做 1：纯代码生成棋盘纹理（零外部资源）

本专题**不附带任何图片**。第一步先教你用代码“画”一张纹理——之后调试、演示、做占位图都用得上，也能避开“下载图片失败”的坑。

在 `src/main.cpp` 里加一个生成 256×256 棋盘纹理的函数：

```cpp
// 纯代码生成一张棋盘格像素（8x8 格，每格 32x32 像素，两色）
static void MakeCheckerPixels(unsigned char* out, int size)
{
    int cell = size / 8;
    for (int y = 0; y < size; ++y)
        for (int x = 0; x < size; ++x)
        {
            bool dark = ((x / cell) + (y / cell)) % 2 == 0;
            unsigned char c = dark ? 200 : 60;          // 深浅两色
            int i = (y * size + x) * 3;                 // RGB 三字节
            out[i] = c; out[i+1] = c; out[i+2] = c;
        }
}

// 把 CPU 像素数组上传为一张 GL 纹理，返回纹理句柄
static unsigned int CreateTextureFromPixels(unsigned char* pixels,
                                            int w, int h)
{
    unsigned int tex;
    glGenTextures(1, &tex);
    glBindTexture(GL_TEXTURE_2D, tex);

    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_REPEAT);
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_T, GL_REPEAT);
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER,
                    GL_LINEAR_MIPMAP_LINEAR);
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_LINEAR);

    glTexImage2D(GL_TEXTURE_2D, 0, GL_RGB, w, h, 0,
                 GL_RGB, GL_UNSIGNED_BYTE, pixels);
    glGenerateMipmap(GL_TEXTURE_2D);
    return tex;
}
```

## 3.4 动手做 2：stb_image 加载真实图片（可选但强烈推荐）

stb_image 是**单头文件**库，无需安装，下载 `stb_image.h`（GitHub `nothings/stb`）放入 `third_party/` 即可。

```cpp
// 在一个 .cpp 里定义一次实现（放 main.cpp 顶部即可）
#define STB_IMAGE_IMPLEMENTATION
#include "stb_image.h"
```

加载并上传：

```cpp
static unsigned int LoadTextureFromFile(const char* path)
{
    int w, h, channels;
    stbi_set_flip_vertically_on_load(true);   // 图片顶部 ↔ OpenGL v=1 顶部 对齐
    unsigned char* data = stbi_load(path, &w, &h, &channels, 0);
    if (!data)
    {
        std::cerr << "加载图片失败: " << path << std::endl;
        return 0;
    }

    // channels：3=RGB, 4=RGBA —— 内部格式与上传格式要匹配
    unsigned int tex = CreateTextureFromPixels(data, w, h);
    stbi_image_free(data);                    // 上传完即可释放 CPU 副本
    return tex;
}
```

> 为什么翻转？图片第 0 行在文件顶部（y 向下），而纹理采样 v=0 在“底部”。翻转后图像才正立。

## 3.5 动手做 3：把纹理画上矩形

### 新增着色器 `shaders/textured.vert`

```glsl
#version 330 core
layout (location = 0) in vec3 aPos;
layout (location = 1) in vec2 aTexCoord;    // 纹理坐标，2 个分量

out vec2 vTexCoord;

void main()
{
    gl_Position = vec4(aPos, 1.0);
    vTexCoord = aTexCoord;
}
```

### 新增着色器 `shaders/textured.frag`

```glsl
#version 330 core
in vec2 vTexCoord;
out vec4 FragColor;

uniform sampler2D uTexture;      // sampler2D = 2D 纹理采样器（与纹理单元绑定）

void main()
{
    FragColor = texture(uTexture, vTexCoord);   // 按插值出的 uv 采样
}
```

### 修改 `src/main.cpp`

顶点数据改为「位置 + 纹理坐标」，并画两个三角形组成的矩形：

```cpp
    // 位置(x,y,z) + 纹理坐标(u,v)，交错排列
    float vertices[] = {
        // 位置              // 纹理坐标
         0.5f,  0.5f, 0.0f,   1.0f, 1.0f,
         0.5f, -0.5f, 0.0f,   1.0f, 0.0f,
        -0.5f, -0.5f, 0.0f,   0.0f, 0.0f,
        -0.5f,  0.5f, 0.0f,   0.0f, 1.0f,
    };
    unsigned int indices[] = { 0, 1, 3,   1, 2, 3 };

    // VBO/VAO 设置与第二章相同，属性改为两段：
    //   location 0：位置，每 5 个 float 取 3 个
    //   location 1：纹理坐标，从第 3 个 float 起取 2 个
    // 跨距 5*sizeof(float)
```

属性设置的核心差异（两种属性同一交错数组）：

```cpp
    glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 5*sizeof(float), (void*)0);
    glEnableVertexAttribArray(0);
    glVertexAttribPointer(1, 2, GL_FLOAT, GL_FALSE, 5*sizeof(float),
                          (void*)(3*sizeof(float)));
    glEnableVertexAttribArray(1);
```

准备纹理与绘制：

```cpp
    // 生成棋盘像素并创建纹理
    const int TEX = 256;
    std::vector<unsigned char> pixels(TEX * TEX * 3);
    MakeCheckerPixels(pixels.data(), TEX);
    unsigned int texture = CreateTextureFromPixels(pixels.data(), TEX, TEX);

    unsigned int program = LinkProgram("shaders/textured.vert",
                                       "shaders/textured.frag");

    // —— 主循环绘制区 ——
        glClear(GL_COLOR_BUFFER_BIT);

        glUseProgram(program);

        glActiveTexture(GL_TEXTURE0);        // 激活纹理单元 0
        glBindTexture(GL_TEXTURE_2D, texture);
        glUniform1i(glGetUniformLocation(program, "uTexture"), 0);
        // “把 sampler2D 设为 0” = 告诉着色器去纹理单元 0 采样

        glBindVertexArray(VAO);
        glDrawElements(GL_TRIANGLES, 6, GL_UNSIGNED_INT, nullptr);
```

**预期结果**：窗口中央一个铺满棋盘格纹理的矩形。

## 3.6 进阶：纹理单元与多纹理混合

GPU 有多个**纹理单元**（`GL_TEXTURE0..GL_TEXTURE15+`），可以同时绑定多张纹理，片元着色器里多次采样后混合。做法：

```cpp
    // 两张纹理分别绑定到单元 0、1
    glActiveTexture(GL_TEXTURE0);
    glBindTexture(GL_TEXTURE_2D, textureA);
    glActiveTexture(GL_TEXTURE1);
    glBindTexture(GL_TEXTURE_2D, textureB);

    glUseProgram(program);
    glUniform1i(glGetUniformLocation(program, "uTexA"), 0);
    glUniform1i(glGetUniformLocation(program, "uTexB"), 1);
```

片元着色器：

```glsl
uniform sampler2D uTexA;
uniform sampler2D uTexB;
uniform float uMix;          // 0 = 全 A，1 = 全 B

void main()
{
    vec4 a = texture(uTexA, vTexCoord);
    vec4 b = texture(uTexB, vTexCoord);
    FragColor = mix(a, b, uMix);          // mix：线性混合
}
```

- 把 `uMix` 用 `glfwGetTime()` 正弦驱动，就能看到两张棋盘纹理**交叉淡入淡出**；
- 内置函数 `mix(a, b, t)`、`texture(采样器, uv)` 是着色器“素材库”里的高频函数。

> 实际项目里纹理单元是省 `glBindTexture` 次数的手段：贴图多的模型一次绘制要绑定 4~8 张（漫反射/法线/高光/自发光…），后面光照章节会再次遇到。

## 3.7 实战与验收

1. **像素风开关**：把 `GL_TEXTURE_MAG_FILTER` 从 `GL_LINEAR` 改成 `GL_NEAREST`，放大窗口看矩形，观察“平滑 vs 颗粒感”，理解滤波参数；
2. **平铺与边缘**：把纹理坐标由 `(0,1)` 区间改成 `(0,3)` 区间（`vertices` 里 uv 放大 3 倍），配合 `GL_REPEAT` 与 `GL_CLAMP_TO_EDGE` 各看一次效果；
3. **让棋盘动起来**：每帧把 uv 整体平移（在 `.vert` 里 `vTexCoord = aTexCoord + uOffset;`），你会得到滚动棋盘；
4. **验收标准**：能默写 `glTexImage2D` 的十个参数大致含义；能解释“为什么需要 mipmap”；能说出采样器 `sampler2D` 与纹理单元的对应关系。

## 本章小结

- 纹理 = “像素图 + 采样参数”，顶点带 uv，片元着色器 `texture()` 采样；
- 三件套参数：环绕（WRAP）、过滤（FILTER + mipmap）、上传（`glTexImage2D`）；
- 图片加载记得翻转 y；程序化生成纹理是调试利器（本专题演示就用它）；
- 纹理单元让一张图“不够就两张”，为光照/后处理铺路。
