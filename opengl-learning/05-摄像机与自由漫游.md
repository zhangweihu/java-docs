## 5.1 摄像机 = 一个“反过来放的模型矩阵”

没有真正的“摄像机对象”。我们只做一件事：**构造 view 矩阵**。它描述“世界相对摄像机如何摆放”。用 GLM 的 `lookAt` 一眼看懂：

```cpp
glm::mat4 view = glm::lookAt(eye, center, up);
// eye   ：摄像机在哪（位置）
// center：看向哪个点（目标）
// up    ：头顶大致方向（通常 (0,1,0)）
```

摄像机需要三个正交基向量：**前(Front)、右(Right)、上(Up)**。有了位置 `cameraPos` 和前向，lookAt 等价于：

```cpp
view = glm::lookAt(cameraPos, cameraPos + cameraFront, glm::vec3(0,1,0));
```

> 注意：上章我们把世界 `translate(-3,0,0)` 得到“往右看”的效果——正是“反着摆世界”= 移动摄像机的直觉。lookAt 只是把这件事封装成了给人看的参数。

## 5.2 欧拉角：用 yaw/pitch 描述朝向

鼠标拖动改变“看向哪里”，用三个角最直观：

- **Yaw（偏航）**：绕上轴左右转（水平转头）；
- **Pitch（俯仰）**：绕右轴上下看；
- **Roll（翻滚）**：本章不用（第一人称不歪头）。

由 yaw/pitch 求前向向量（方向余弦，可记忆为“球坐标投影”）：

```cpp
glm::vec3 front;
front.x = cos(glm::radians(yaw)) * cos(glm::radians(pitch));
front.y = sin(glm::radians(pitch));
front.z = sin(glm::radians(yaw)) * cos(glm::radians(pitch));
cameraFront = glm::normalize(front);
```

- 初始：`yaw = -90°`（朝向 -Z 轴）、`pitch = 0`；
- **万向锁**：pitch 限制在 ±89° 防止“翻跟头”后左右键方向错乱（第一人称经典坑）。

## 5.3 deltaTime：让移动速度与帧率无关

`glfwGetTime()` 是“从启动到现在经过的秒数”。每帧记下时间差：

```cpp
float currentFrame = (float)glfwGetTime();
float deltaTime = currentFrame - lastFrame;   // 上一帧到这一帧耗时（秒）
lastFrame = currentFrame;
```

移动时**位移 = 速度 × 时间**：

```cpp
float velocity = 2.5f * deltaTime;   // 每秒 2.5 单位
if (forward) cameraPos += cameraFront * velocity;
```

- 60 FPS 时每帧约 0.016s；deltaTime 让“每帧走 0.01”变成“每秒走 2.5”——高刷屏/低配机速度一致；
- 忘写 deltaTime 的典型症状：高性能电脑上物体“飞”一样快。

## 5.4 动手做：实现可自由漫游的场景

沿用第四章工程（36 顶点立方体），新增摄像机逻辑。

### 新增文件 `src/camera.h`

```cpp
#pragma once
#include <glm/glm.hpp>
#include <glm/gtc/matrix_transform.hpp>

// 极简 FPS 摄像机：位置 + yaw/pitch + 鼠标灵敏度
class Camera
{
public:
    glm::vec3 Position {0.0f, 0.0f, 3.0f};
    glm::vec3 Front    {0.0f, 0.0f, -1.0f};
    glm::vec3 Up       {0.0f, 1.0f, 0.0f};

    float Yaw   = -90.0f;
    float Pitch = 0.0f;
    float Fov   = 45.0f;                       // 视野角（滚轮缩放改这个）
    float Sensitivity = 0.1f;

    void RecalculateFront()                    // 由 yaw/pitch 求前向
    {
        glm::vec3 f;
        f.x = cos(glm::radians(Yaw)) * cos(glm::radians(Pitch));
        f.y = sin(glm::radians(Pitch));
        f.z = sin(glm::radians(Yaw)) * cos(glm::radians(Pitch));
        Front = glm::normalize(f);
    }

    void ProcessMouse(float xoffset, float yoffset)   // 鼠标移动量
    {
        xoffset *= Sensitivity;
        yoffset *= Sensitivity;
        Yaw   += xoffset;
        Pitch -= yoffset;                     // 屏幕 y 向上=俯仰角减小
        if (Pitch > 89.0f)  Pitch = 89.0f;
        if (Pitch < -89.0f) Pitch = -89.0f;
        RecalculateFront();
    }

    glm::mat4 GetViewMatrix() const
    {
        return glm::lookAt(Position, Position + Front, Up);
    }
};
```

### 修改 `src/main.cpp`

全局变量存窗口与摄像机（回调要用）：

```cpp
// 上一帧时间戳、摄像机实例、首帧鼠标标记
static float gLastFrame = 0.0f;
static Camera gCamera;
static bool  gFirstMouse = true;
static float gLastX = 400.0f, gLastY = 300.0f;
```

输入回调（放在 `main()` 之前）：

```cpp
// 鼠标在窗口内移动（或按住时）
static void MouseCallback(GLFWwindow* window, double xpos, double ypos)
{
    (void)window;
    if (gFirstMouse)                 // 防止“跳帧”：首帧只记录不旋转
    {
        gLastX = (float)xpos;
        gLastY = (float)ypos;
        gFirstMouse = false;
    }
    gCamera.ProcessMouse((float)xpos - gLastX, gLastY - (float)ypos);
    gLastX = (float)xpos;
    gLastY = (float)ypos;
}

// 滚轮：缩放视野
static void ScrollCallback(GLFWwindow* window, double xoffset, double yoffset)
{
    (void)window; (void)xoffset;
    gCamera.Fov -= (float)yoffset;
    if (gCamera.Fov < 1.0f)  gCamera.Fov = 1.0f;
    if (gCamera.Fov > 90.0f) gCamera.Fov = 90.0f;
}
```

`main()` 中创建窗口后注册回调与捕获鼠标：

```cpp
    // 让鼠标“隐形且锁定在窗口内”（第一人称标配），Esc 退出时才释放
    glfwSetInputMode(window, GLFW_CURSOR, GLFW_CURSOR_DISABLED);
    glfwSetCursorPosCallback(window, MouseCallback);
    glfwSetScrollCallback(window, ScrollCallback);
```

处理每帧键盘输入（放主循环开头，用 deltaTime）：

```cpp
        float now = (float)glfwGetTime();
        float deltaTime = now - gLastFrame;
        gLastFrame = now;

        float speed = 2.5f * deltaTime;              // 每秒 2.5 米
        if (glfwGetKey(window, GLFW_KEY_W) == GLFW_PRESS)
            gCamera.Position += speed * gCamera.Front;
        if (glfwGetKey(window, GLFW_KEY_S) == GLFW_PRESS)
            gCamera.Position -= speed * gCamera.Front;
        if (glfwGetKey(window, GLFW_KEY_A) == GLFW_PRESS)
            gCamera.Position -= glm::normalize(
                glm::cross(gCamera.Front, gCamera.Up)) * speed;   // 左
        if (glfwGetKey(window, GLFW_KEY_D) == GLFW_PRESS)
            gCamera.Position += glm::normalize(
                glm::cross(gCamera.Front, gCamera.Up)) * speed;   // 右
```

- 左/右方向：前向 `cross` 上向量 = 右向量；加负号向左；
- `cross` 结果记得 `normalize`（Front/Up 虽归一但叉积不一定）。

主循环里替换视图与投影矩阵：

```cpp
        glm::mat4 view = gCamera.GetViewMatrix();
        glm::mat4 projection = glm::perspective(
            glm::radians(gCamera.Fov),
            800.0f / 600.0f, 0.1f, 100.0f);
        // ...继续 glUniformMatrix4fv 上传 uView/uProjection，uModel 保持旋转——
```

**想要更像“场景”**：绕原点摆一圈立方体（复用同一 VBO，多画几次，每次不同 `translate` + 随机旋转速度），你就能在里面“走”。

## 5.5 逐行答疑

| 你可能会问 | 答案 |
| --- | --- |
| 鼠标回调为什么 `yoffset` 要取负？ | 屏幕 y 向下为正；拖鼠标向上（期望抬头）时 y 减小，pitch 应增大，故 `Pitch -= yoffset` |
| 为什么 W/S 用 Front，A/D 用叉积？ | 前后就是视线方向；左右是“垂直于视线与上向量”的方向，叉积现算最稳 |
| `GLFW_CURSOR_DISABLED` 是啥？ | 光标消失并锁定在窗口中央，避免拖出窗口边缘；退出时想恢复可 `glfwSetInputMode(..., GLFW_CURSOR_NORMAL)` |
| 立方体转太快/场景移动很怪？ | 检查是否统一用了 `deltaTime`；检查 `gLastFrame` 是否在循环内更新 |
| 按 Esc 后鼠标没回来？ | 退出主循环前调一次 `glfwSetInputMode(window, GLFW_CURSOR, GLFW_CURSOR_NORMAL)` |

## 5.6 实战与验收

1. **绕场一周**：在场景里放 6~8 个位置随机、转速不同的立方体（每帧给各自 `uModel`），用 WASD + 鼠标在其中穿梭，感受“深度测试 + 摄像机”的组合；
2. **视角缩放**：滚轮缩放已改 `Fov`，观察 1°（长焦）与 90°（广角）的透视差异；
3. **前后向与左右向混合移动**：同时按 W 与 A 应沿斜向走（因为每帧分开累加）——若觉得斜向更快，说明你把两段位移写成了只更新一次 `speed`（应为两段都乘 deltaTime）；
4. **验收标准**：能说出 lookAt 三个参数含义、yaw/pitch 到前向的公式推导思路、deltaTime 为什么必须乘；能解释 `cross(Front, Up)` 得到的向量是“右”而非“左”。

## 本章小结

- 摄像机本质是 view 矩阵：`lookAt(pos, pos+front, up)`；
- yaw/pitch 欧拉角 + 鼠标偏移 = 自由视角；pitch ±89° 防万向锁；
- `deltaTime` 乘速度 = 帧率无关移动；
- **主线至此收官**：窗口 → 三角形 → 纹理 → 3D 变换 → 自由漫游，你已经能走进自己搭的 3D 世界。下一章进阶：给这个世界打光。
