## 为什么从 OpenGL 学图形学

- **它是显卡的“普通话”**：OpenGL 是直接面向 GPU 的标准 API，现代游戏引擎（Unity/Unreal）和 Web（WebGL）底层思路都源自这条管线；会了它，引擎里很多“为什么”立刻有答案（本项目另有 [unity-learning](../csharp-learning/unity-learning/README.md) 讲引擎层）；
- **一次配置，终身受用**：窗口（GLFW）、函数指针加载（glad）、数学库（GLM）三件套是所有 OpenGL/C++ 教程的通用起手式；
- **代码量小、反馈即时**：几百行就能看到一个会旋转、可漫游、有光照的 3D 场景，成就感曲线非常陡；
- **语言中立**：你不需要先精通 C++。第 01 章有一节“C++ 最少实用子集”，后续示例刻意只用最常用的写法（`vector`/类/`std::string`），会 Java/Python/C#/Rust 即可跟上。

## 环境要求与版本说明

| 组件 | 建议版本 | 说明 |
| --- | --- | --- |
| C++ 编译器 | C++17 | Windows：Visual Studio 2022（MSVC）或 MinGW-w64；Linux：GCC 9+；macOS：Xcode CLT |
| CMake | 3.16+ | 所有示例用 CMake 组织（01 章给可直接用的模板） |
| OpenGL | 3.3 Core Profile | 本文档全部示例基于 3.3 核心模式；2008 年后的独显/集显基本都支持 |
| GLFW | 3.4 | 窗口、OpenGL 上下文、键盘/鼠标输入 |
| glad | glad2（在线生成） | 加载 OpenGL 函数指针（为何需要见 01 章 §1.3） |
| GLM | 0.9.9+ | Header-only 数学库，仿 GLSL 风格 |
| stb_image | 单头文件版 | 第 03 章加载 PNG/JPG 用（可选，我们也会用程序化纹理避免外链图片） |

- 代码刻意使用 **OpenGL 3.3 老式管线 + 旧式可复制流程**，与绝大多数中文教程（LearnOpenGL 等）一致；同时也兼容 WebGL 2 思维迁移。
- **写作与校验说明**：本文档编写时本机暂未配置 C++/OpenGL 环境，全部代码**未经实机编译**。第一章工程模板基于官方推荐的最小配置编写，请在本地按章验证；个别库的在线生成文件布局/命名若有差异，以你实际生成与 CMake 日志为准（章节内已有常见报错对照表）。

## 工程模板约定（重要）

本专题**不提供随书工程**，但为了让你“复制即用”，所有示例遵循同一约定：

```text
opengl-playground/
├── CMakeLists.txt            # 01 章 §1.4 提供的模板，之后不用再改
├── third_party/
│   ├── glad/                 # glad2 在线生成解压后放入（include/ + src/）
│   ├── glfw/                 # GLFW 源码（CMake FetchContent 或下载放入）
│   └── glm/                  # GLM header-only
├── shaders/                  # .vert/.frag 着色器源码文件（随章新增）
└── src/
    └── main.cpp              # 每章替换为最新版
```

- 第一章给出的 `CMakeLists.txt` 是**一次性配置**，后续章节不再贴重复的 CMake；
- 第二~八章的代码头部都注明「沿用上一章工程，新增/修改如下文件」；
- 各章“完整示例”尽量**自成一段**：需要新工具类（如 `Shader`、`Camera`、`Texture`）时会给出完整头文件 + 实现，你新建对应文件即可。

## 常见资源

- [LearnOpenGL CN](https://learnopengl-cn.github.io/)：本专题主要参考与深化方向，章节顺序大致对应；
- [docs.GL](https://docs.gl/) / [OpenGL Reference](https://www.khronos.org/registry/OpenGL-Refpages/gl4/)：查函数签名的官方速查；
- [GLSL 规范](https://registry.khronos.org/OpenGL/specs/gl/GLSLangSpec.4.60.pdf)：需要精确语义时再翻；
- [ShaderToy](https://www.shadertoy.com/)：海量片元着色器实践，练手感神器；
- 调试工具：RenderDoc（帧调试）、NVIDIA Nsight / 扩展 `GL_ARB_debug_output`。

## 学习建议

1. 第一章认真搭工程，**一次成功**，后面每章都是增量改动——这是全专题最“苦”的一步；
2. 每章先复制代码跑出效果，再回头看概念小节，最后做“实战与验收”里的三个小改造；
3. 着色器是图形学“心脏”，第二章起建议把 GLSL 当一门小语言精读；改一个数字、看一次画面，是理解它的最好方式；
4. 遇到“黑屏/白屏”先看控制台日志，第七章有专门的调试对照表；
5. 学完第八章后，推荐打开 [unity-learning](../csharp-learning/unity-learning/README.md) 的着色器/后处理相关章节，把“底层 API”与“引擎封装”对照着看一遍。
