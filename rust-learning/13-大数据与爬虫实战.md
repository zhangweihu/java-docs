## 13.1 Rust 在数据管道中的生态位

对照 java 大数据体系（61~65 章），Rust 侧对应的原生数据栈：

| 环节 | Java 体系 | Rust 体系 | 说明 |
| --- | --- | --- | --- |
| 存储 | HDFS/Hive/Parquet | 本地 FS + **Parquet** | Parquet 列式文件两侧通用 |
| 处理/分析 | Spark/Polars(独立) | **Polars** | 单机内"超 pandas"计算 |
| SQL 引擎 | Hive/Spark SQL/Doris | **DataFusion** | 内存 DataFrame + SQL |
| 流式 | Flink | rdkafka(消费) | Rust 侧流处理仍偏新兴 |
| 采集 | Flume/爬虫框架 | reqwest + scraper | 轻量自建 |

**关键**：因为都在 Arrow/Parquet 上，Rust 管道与 Spark/Hive 的产物可互换——这是生态红利。

## 13.2 爬虫工程：礼仪与最小实现

爬虫的三个职业底线：**声明身份（User-Agent）、遵守站点规则（robots.txt/服务条款）、限速不骚扰**。然后才是技术。

最小实现（同步 reqwest + scraper）：

```toml
[dependencies]
reqwest = { version = "0.12", features = ["blocking", "json"] }
scraper = "0.20"
anyhow = "1"
serde = { version = "1", features = ["derive"] }
serde_json = "1"
```

```rust
use reqwest::blocking::Client;
use scraper::{Html, Selector};

const UA: &str = "my-learning-spider/0.1 (+https://example.com/about)";

fn main() -> anyhow::Result<()> {
    let client = Client::builder()
        .user_agent(UA)
        .timeout(std::time::Duration::from_secs(10))
        .build()?;

    // 用文档类页面示范（请换成目标站点允许抓取的页面）
    let html = client.get("https://www.rust-lang.org/").send()?.text()?;

    let document = Html::parse_document(&html);
    let title_sel = Selector::parse("title").unwrap();
    if let Some(title) = document.select(&title_sel).next() {
        println!("页面标题: {}", title.text().collect::<String>());
    }

    // 提取所有外链
    let a_sel = Selector::parse("a").unwrap();
    let links: Vec<String> = document
        .select(&a_sel)
        .filter_map(|el| el.value().attr("href"))
        .map(str::to_string)
        .collect();
    println!("共 {} 个链接", links.len());
    for link in links.iter().take(5) {
        println!("  {link}");
    }
    Ok(())
}
```

要点：

- 用 `Html::parse_document` 容错解析（不要求 XHTML 严格）；
- `Selector::parse("div.item > h2.title a")` 支持 CSS 选择器；
- `el.value().attr("href")` 取属性；相对 URL 要 `Url::join` 补全；
- **遵守重试与状态码**：429/5xx 需退避，503 说明被限流。

## 13.3 异步并发爬取：限速 + 通道

批量 URL 用第 7 章能力并发抓取，但**必须限流**（信号量控制最大并发数）：

```rust
use std::sync::Arc;
use std::time::Duration;
use tokio::sync::Semaphore;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let client = reqwest::Client::builder()
        .user_agent("learning-spider/0.1")
        .build()?;

    let urls: Vec<String> = (1..=10).map(|i| format!("https://example.com/page/{i}")).collect();
    let semaphore = Arc::new(Semaphore::new(3));        // 最多 3 并发

    let mut handles = Vec::new();
    for url in urls {
        let permit = semaphore.clone().acquire_owned().await?;  // 获取令牌（限速）
        let client = client.clone();
        handles.push(tokio::spawn(async move {
            let _guard = permit;                      // drop 即释放令牌
            match client.get(&url).send().await {
                Ok(resp) => {
                    let status = resp.status().as_u16();
                    let size = resp.text().await.map(|t| t.len()).unwrap_or(0);
                    println!("{url} -> {status}, {size} bytes");
                }
                Err(e) => println!("{url} -> 失败: {e}"),
            }
        }));
    }
    for h in handles {
        h.await?;
    }
    Ok(())
}
```

> 优雅抓取 = 并发（性能）× 信号量（礼貌）× 超时（稳定）× 重试（健壮）。真实项目还要持久化抓取状态，支持断点续抓。

## 13.4 结构化落地：清洗 → CSV/Parquet

解析到的数据统一为结构体，然后批量写入 Parquet（列式、可压缩、跨引擎可读）：

```rust
use polars::prelude::*;
use serde::Deserialize;

#[derive(Debug, Deserialize)]
struct Article {
    title: String,
    url: String,
    word_count: usize,
}

fn main() -> anyhow::Result<()> {
    // 模拟一批解析结果
    let articles = vec![
        Article { title: "Intro to Polars".into(), url: "https://x/1".into(), word_count: 1200 },
        Article { title: "Unsafe Rust".into(), url: "https://x/2".into(), word_count: 3400 },
        Article { title: "FFI guide".into(), url: "https://x/3".into(), word_count: 900 },
    ];

    // 用 serde + polars 的 Struct 便捷建 DataFrame
    let df = df![
        "title" => articles.iter().map(|a| a.title.as_str()).collect::<Vec<_>>(),
        "url"   => articles.iter().map(|a| a.url.as_str()).collect::<Vec<_>>(),
        "word_count" => articles.iter().map(|a| a.word_count as i64).collect::<Vec<_>>(),
    ]?;

    let mut file = std::fs::File::create("articles.parquet")?;
    ParquetWriter::new(&mut file).finish(&df)?;
    println!("已保存 {} 条到 articles.parquet", articles.len());
    Ok(())
}
```

更通用的做法：把结构体序列化为 JSON 流或用 arrow-rs 直接构建列，这里用 `df!` 演示最小路径。

## 13.5 DataFusion：对数据文件跑 SQL

DataFusion 是 Rust 的内存 SQL 查询引擎（Arrow 项目成员），**不需要外部服务**就能对 CSV/Parquet/内存表执行标准 SQL：

```toml
[dependencies]
datafusion = "40"
```

```rust
use datafusion::prelude::*;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let ctx = SessionContext::new();

    // 把 parquet 文件注册成表 articles
    ctx.register_parquet("articles", "articles.parquet", ParquetReadOptions::default()).await?;

    // 直接用 SQL 查询（谓词下推到 Parquet，只读需要的行/列）
    let df = ctx
        .sql("SELECT title, word_count FROM articles WHERE word_count > 1000 ORDER BY word_count DESC")
        .await?;
    df.show().await?;                      // DataFrame 实现表格打印

    // 聚合也一样是标准 SQL
    let agg = ctx
        .sql("SELECT count(*) AS cnt, avg(word_count) AS avg_words, max(word_count) AS max_words FROM articles")
        .await?;
    agg.show().await?;
    Ok(())
}
```

DataFusion 的能力与注意点：

- `register_csv/register_parquet/register_arrow`，也支持 `ctx.sql("CREATE EXTERNAL TABLE ...")`；
- 谓词/投影/排序都会下推，内置优化器对标 Spark Catalyst 的简化版；
- 还支持 UDF/UDAF、`CREATE VIEW`、多文件 glob（`dir/*.parquet`）；
- 进阶：`datafusion-cli` 是可交互的 SQL shell（`cargo install datafusion-cli`），适合本地实验。

## 13.6 实战：全链路新闻聚合管道

**需求**：抓取一组 URL 的标题与正文字数 → 清洗成结构化数据 → 写 Parquet → 用 SQL 产出"最长 Top5 / 平均字数 / 大于 2000 字的占比"。

完整主流程（合并 13.2~13.5，允许目标改为你自己的合法数据源）：

```rust
// 1) 抓取（异步 + 限速）——略，见 13.3
// 2) 结构化：每篇 (title, url, word_count)
// 3) 落地 articles.parquet（见 13.4）
// 4) SQL 分析：
#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let ctx = SessionContext::new();
    ctx.register_parquet("articles", "articles.parquet", ParquetReadOptions::default()).await?;

    let top = ctx.sql(
        "SELECT title, word_count FROM articles
         ORDER BY word_count DESC LIMIT 5"
    ).await?;
    top.show().await?;

    let stats = ctx.sql(
        "SELECT count(*) AS articles,
                round(avg(word_count), 1) AS avg_words,
                sum(CASE WHEN word_count > 2000 THEN 1 ELSE 0 END) AS long_articles
         FROM articles"
    ).await?;
    stats.show().await?;
    Ok(())
}
```

**验收清单**：

1. 13.2 的同步版能打印目标页标题与链接数；
2. 13.3 异步版：观察并发上限 3 生效（可在日志中加时间戳对比），且程序快速结束（总耗时 ≈ ceil(N/3) × 单次耗时）；
3. 造 50 条模拟文章写入 `articles.parquet`，SQL 统计与手算一致；
4. 修改 SQL 做 `GROUP BY` 聚合（如按 URL 域名统计文章数）；
5. 追加一次抓取的数据到既有 Parquet 后重新查询——理解"增量采集 + 全量分析"的现实形态。

**扩展方向**：

- **流式**：`rdkafka` 消费 Kafka topic → 清洗 → 写 Parquet（对照 java-learning 62 章实时数仓的 Rust 版雏形）；
- **存储分层**：文件即"数据湖"——`raw/`、`clean/` 多目录，用 DataFusion 建视图做血缘查询；
- **服务化**：把 13.5 封成 axum 的 `/api/query`（DataFusion 提供异步 `df.collect()`，可无缝进 08 章服务）；
- 用 `object_store` + S3/MinIO 让 DataFusion 直接查询云上对象存储。
