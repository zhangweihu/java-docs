# mall-boot 文件说明（逐文件说明）

> 本文档按目录列出**每一个文件**的职责。文件夹级说明见《项目结构说明.md》。

## 一、根目录文件

| 文件 | 说明 |
| --- | --- |
| `README.md` | 项目总览：技术栈、快速开始、目录结构、知识点索引、FAQ |
| `pom.xml` | Maven 构建文件。继承 spring-boot-starter-parent 统一管版本；依赖：web/validation/data-redis/MyBatis-Plus/MySQL/jjwt/springdoc/Lombok；插件：spring-boot-maven-plugin 生成可执行 jar |
| `.gitignore` | 忽略 target/、IDE 配置、日志、本地敏感配置（application-local.yml） |

## 二、`sql/`

| 文件 | 说明 |
| --- | --- |
| `mall.sql` | 建库 `mall` + 三张表（t_user/t_product/t_order）+ 3 条演示商品。含唯一索引（username、order_no）与组合索引（status+create_time 供超时关单扫描） |

## 三、`docker/`

| 文件 | 说明 |
| --- | --- |
| `Dockerfile` | 三阶段构建：builder(maven:3.9) 编译 jar -> agent 下载 SkyWalking Java Agent(9.1.0) -> runtime(temurin:17-jre) 非 root 运行；内置 JVM 参数（-Xms/-Xmx/G1GC）、东八区时区、`JAVA_TOOL_OPTIONS=-javaagent` 自动上报探针 |
| `docker-compose.yml` | 三个服务：mysql(挂载 sql 初始化+健康检查)、redis、mall-boot(依赖健康检查通过后启动)。生产环境变量全部通过 environment 注入 |
| `docker-compose.skywalking.yml` | （覆盖文件）追加 oap + ui 两个服务，并把 mall-boot 的探针上报地址改为 `oap:11800`；用法：`docker compose -f docker-compose.yml -f docker-compose.skywalking.yml up -d --build` |

## 3.5、`k8s/`（Kubernetes 部署清单）
| 文件 | 说明 |
| --- | --- |
| `namespace.yaml` | mall-boot 命名空间 |
| `configmap.yaml` | 应用环境变量（SPRING_DATASOURCE_* / REDIS 等，envFrom 整体注入） |
| `secret.yaml` | MySQL 密码 / JWT 密钥（base64，生产务必替换） |
| `mysql.yaml` | MySQL 8 StatefulSet + PVC + Headless Service；初始化 SQL 由 ConfigMap mall-init-sql 挂载 |
| `redis.yaml` | Redis 7 Deployment + PVC |
| `mall-boot.yaml` | 应用 Deployment（2 副本、探针、环境注入）+ Service |
| `ingress.yaml` | nginx Ingress（host: mall.local） |
| `README.md` | 镜像构建、部署步骤、验证命令、运维命令 |

## 3.6、`helm/`（Helm Chart 部署）
| 文件 | 说明 |
| --- | --- |
| `Chart.yaml` / `values.yaml` | Chart 元数据 + 全部可配置项（镜像/副本/密钥/基础设施开关/Ingress） |
| `files/mall.sql` | MySQL 初始化脚本（模板 `.Files.Get` 渲染进 init ConfigMap） |
| `templates/configmap.yaml` / `secret.yaml` | 非敏感环境变量（envFrom 注入）+ 敏感配置（b64） |
| `templates/deployment.yaml` / `service.yaml` | 应用 Deployment（副本/探针/envFrom）+ Service |
| `templates/mysql.yaml` / `redis.yaml` | 可选 MySQL StatefulSet（自动建表）+ Redis Deployment，均可独立开关 |
| `templates/ingress.yaml` / `NOTES.txt` | Ingress + 安装后提示 |
| `README.md` | 快速开始、参数表、复用外部基础设施、与 k8s/ 清单的关系 |

## 四、`src/main/java/com/mall/`

### 4.1 根包
| 文件 | 说明 |
| --- | --- |
| `MallApplication.java` | 启动类。@EnableAsync 开异步邮件、@EnableScheduling 开定时任务、@MapperScan 扫 Mapper |

### 4.2 `common/`
| 文件 | 说明 |
| --- | --- |
| `Result.java` | 统一响应体（code/message/data），静态方法 ok()/fail() |
| `ResultCode.java` | 返回码枚举：200 成功、4xxx 客户端错误、5xxx 服务端错误 |
| `BusinessException.java` | 业务异常，携带 code；Service 校验失败直接抛出 |
| `GlobalExceptionHandler.java` | @RestControllerAdvice 全局兜底：业务异常/参数校验/兜底 500，并记录 ERROR 日志 |

### 4.3 `config/`
| 文件 | 说明 |
| --- | --- |
| `RedisConfig.java` | RedisTemplate 序列化：key 用 String、value 用 JSON（GenericJackson2Json） |
| `MybatisPlusConfig.java` | 注册分页插件、乐观锁插件；MetaObjectHandler 自动填充 createTime/updateTime |
| `WebMvcConfig.java` | 注册 JwtInterceptor，配置登录/商品浏览/文档等白名单 |
| `JwtConfig.java` | @ConfigurationProperties 绑定 `mall.jwt.*`，提供 HS256 SecretKey |

### 4.4 `controller/`
| 文件 | 说明 |
| --- | --- |
| `UserController.java` | /user：register(注册)、login(登录发Token)、logout(登出拉黑) |
| `ProductController.java` | /product：list(公开列表)、detail(带缓存详情)、add(新增演示) |
| `OrderController.java` | /order：create(下单防超卖)、pay/callback(支付回调)、detail(归属校验) |
| `CartController.java` | /cart：add/list/update/remove（Redis Hash 购物车） |
| `RedisVerifyController.java` | /api/redis/verify：Redis 实际对接自检接口（返回六步验证报告） |

### 4.5 `service/` + `service/impl/`
| 文件 | 说明 |
| --- | --- |
| `UserService.java` / `UserServiceImpl.java` | 注册（用户名查重+BCrypt 加密）、登录（校验+发Token，错误统一提示防账号探测）、登出（Token 拉黑） |
| `ProductService.java` / `ProductServiceImpl.java` | 列表、详情（Cache Aside + 互斥锁防击穿 + 随机TTL防雪崩 + 空值缓存防穿透）、新增后删缓存 |
| `OrderService.java` / `OrderServiceImpl.java` | **下单三件套**：@Transactional 事务 + setnx 分布式锁 + SQL 乐观扣减；支付回调幂等状态机；订单归属校验；超时关单 |
| `CartService.java` / `CartServiceImpl.java` | 购物车 Hash 操作，hincrby 原子累加 |
| `RedisVerifyService.java` | Redis 对接验证：Ping / String+TTL / Hash 购物车 / List 队列 / Set 去重 / 分布式锁 六步自检，逐步计时、单步失败不中断，输出可读报告 |

### 4.6 `mapper/`
| 文件 | 说明 |
| --- | --- |
| `UserMapper.java` | 用户 CRUD |
| `ProductMapper.java` | 商品 CRUD + **@Update 乐观扣减库存 SQL**（stock>=quantity 防超卖） |
| `OrderMapper.java` | 订单 CRUD |

### 4.7 `entity/`
| 文件 | 说明 |
| --- | --- |
| `User.java` | t_user：@TableLogic 逻辑删除、@JsonIgnore 隐藏密码、字段自动填充 |
| `Product.java` | t_product：价格用 BigDecimal |
| `Order.java` | t_order：orderNo 唯一、价格快照、状态机字段注释 |

### 4.8 `dto/` / `vo/`
| 文件 | 说明 |
| --- | --- |
| `RegisterDTO.java` | 注册入参：用户名/密码长度、手机号正则校验 |
| `LoginDTO.java` | 登录入参：非空校验 |
| `CreateOrderDTO.java` | 下单入参：productId 非空、quantity>=1 |
| `LoginVO.java` | 登录出参：token + 用户基础信息 |
| `ProductVO.java` | 商品出参：只暴露展示字段 |

### 4.9 `util/`
| 文件 | 说明 |
| --- | --- |
| `JwtUtil.java` | 签发/解析 JWT（HS256），过期或签名错误抛 401 |
| `OrderNoGenerator.java` | 订单号生成：时间戳+随机数+用户尾号（生产可换雪花算法） |
| `RedisKeyUtil.java` | 统一 Key 规范：product:detail、cart、lock:order、token:blacklist |

### 4.10 `interceptor/`
| 文件 | 说明 |
| --- | --- |
| `JwtInterceptor.java` | 解析 Authorization: Bearer Token；内含 UserContext（ThreadLocal），afterCompletion 清理防串号 |

### 4.11 `job/`
| 文件 | 说明 |
| --- | --- |
| `OrderTimeoutJob.java` | @Scheduled 每 60s 关闭超过 30 分钟未支付的订单（initialDelay 10s） |

### 4.12 `runner/`
| 文件 | 说明 |
| --- | --- |
| `RedisConnectivityRunner.java` | ApplicationRunner 启动自检：Ping + 写入 30s 探针 key；失败仅告警不阻断启动（缓存/锁降级，主流程可用） |

## 五、`src/main/resources/`
| 文件 | 说明 |
| --- | --- |
| `application.yml` | 主配置：端口 8080、profile=dev、JWT 默认密钥、MyBatis-Plus 逻辑删除/驼峰/SQL 打印、Swagger 路径 |
| `application-dev.yml` | 本地 MySQL(root/root)、Redis localhost:6379、日志 debug |
| `application-prod.yml` | 生产配置：DB_HOST/DB_PASSWORD/REDIS_HOST/JWT_SECRET 全部环境变量注入，Hikari 连接池调优，关闭 SQL 打印，日志落盘 |

## 六、`src/test/java/com/mall/`
| 文件 | 说明 |
| --- | --- |
| `OrderServiceTest.java` | 冒烟测试：下单返回订单号、库存不足抛业务异常。需本地 MySQL/Redis 就绪 |
| `RedisIntegrationTest.java` | Redis 真实对接集成测试（连真 Redis 非 mock）：ping / string+ttl / hash 购物车 / list / set 去重 / 分布式锁互斥与释放，六项断言。前置 `docker compose -f docker/docker-compose.yml up -d redis`，运行 `mvn test -Dtest=RedisIntegrationTest` |
