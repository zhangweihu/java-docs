# mall-cloud 文件说明（逐文件说明）

> 本文档按模块列出**每一个文件**的职责。文件夹级说明见《项目结构说明.md》。

## 一、根目录

| 文件 | 说明 |
| --- | --- |
| `pom.xml` | 父 POM：聚合 5 模块；import spring-cloud 2023.0.1 + spring-cloud-alibaba 2023.0.1.0 两个 BOM |
| `README.md` | 架构总览、模块清单、快速开始、知识点索引、FAQ |
| `.gitignore` | 忽略 target/、IDE 配置、日志 |

## 二、`sql/`
| 文件 | 说明 |
| --- | --- |
| `mall_user.sql` | 建 mall_user 库 + t_user 表 + undo_log 表 |
| `mall_product.sql` | 建 mall_product 库 + t_product 表（含 3 条演示商品）+ undo_log 表 |
| `mall_order.sql` | 建 mall_order 库 + t_order 表 + undo_log 表 |

## 三、`docker/`
| 文件 | 说明 |
| --- | --- |
| `docker-compose.yml` | mysql(挂 3 个 SQL 自动建库)、redis、nacos(v2.3.2 standalone + 健康检查)、seata-server(1.8.0)、sentinel-dashboard(1.8.6，控制台 8858) |
| `seata/registry.conf` | Seata Server 注册中心配置：注册到 Nacos（SEATA_GROUP） |
| `seata/file.conf` | Seata 事务分组映射：`mall_tx_group -> default`（与订单服务客户端一致） |
| `skywalking/docker-compose.yml` | SkyWalking OAP(9.7.0, H2 存储) + UI(8086)，探针上报端口 11800 |
| `skywalking/README.md` | 探针接入指南：IDE VM options / Docker / K8s 三种方式 + 验证步骤 + 常用配置项 |
| `service/Dockerfile` | 微服务通用镜像（构建参数 JAR_FILE/SW_AGENT_NAME；内置 SkyWalking 探针，非 root 运行） |
| `nacos-config/mall-order-flow-rules.json` 等 4 个 JSON | **Sentinel 规则配置中心化**：流控/网关流控/API 分组规则定义（发布到 Nacos，group=SENTINEL_GROUP） |
| `nacos-config/init-sentinel-rules.sh` / `.ps1` | 一键发布 4 条规则到 Nacos（幂等，Nacos Open API v2；改规则后重跑即实时生效） |
| `nacos-config/README.md` | 规则配置中心化：架构图、规则清单、使用步骤、动态调优与生产建议 |

## 四、`mall-common/`
| 文件 | 说明 |
| --- | --- |
| `pom.xml` | 依赖：web、validation、openfeign、lombok（均被服务模块继承复用） |
| `Result.java` | 统一响应体（含 isSuccess() 供 Feign 消费方判断） |
| `BusinessException.java` | 业务异常（code+message） |
| `GlobalExceptionHandler.java` | 全局异常兜底：业务异常/参数校验/500，打包在 common 一处维护 |
| `feign/ProductClient.java` | **商品服务契约**：getPrice、deductStock，path=/internal/product |
| `feign/UserClient.java` | **用户服务契约**：getNickname，path=/internal/user |

## 五、`mall-gateway/`
| 文件 | 说明 |
| --- | --- |
| `pom.xml` | gateway + nacos-discovery + loadbalancer + **sentinel + sentinel-gateway + sentinel-datasource-nacos** + jjwt（WebFlux 栈，无 web starter） |
| `GatewayApplication.java` | 网关启动类 |
| `filter/AuthGlobalFilter.java` | 全局过滤器（Order=-100）：白名单放行 -> JWT 验签 -> 注入 X-User-Id 给下游；失败 401 |
| `config/GatewaySentinelConfig.java` | 网关限流兜底响应：自定义 429 JSON（**规则已配置中心化**：由 Nacos 数据源 gw-flow/gw-api-group 拉取，见 application.yml） |
| `application.yml` | 端口 8080、路由（user/product/order 三条 lb://）、跨域、Nacos 注册、Sentinel 控制台 + **gw-flow / gw-api-group Nacos 数据源** |

## 六、`mall-user/`
| 文件 | 说明 |
| --- | --- |
| `pom.xml` | common + nacos-discovery/config + mybatis-plus + mysql |
| `UserApplication.java` | 启动类：@EnableDiscoveryClient、@ComponentScan("com.mall") 让 common 的异常处理器生效 |
| `entity/User.java` | t_user 实体（@TableLogic 逻辑删除、@JsonIgnore 密码） |
| `mapper/UserMapper.java` | 用户 CRUD |
| `service/UserService.java` | 接口：register/login/getNickname/getById |
| `service/impl/UserServiceImpl.java` | 实现：BCrypt 加密、登录发 JWT（密钥与网关一致）、用户名查重 |
| `controller/UserController.java` | 对外 /user/register、/user/login；内部 /internal/user/**（网关不放行） |
| `application.yml` | 端口 8081、mall_user 库、Nacos、JWT 配置（环境变量注入） |

## 七、`mall-product/`
| 文件 | 说明 |
| --- | --- |
| `pom.xml` | 同 user 模块结构 + **sentinel + sentinel-datasource-nacos** |
| `ProductApplication.java` | 商品服务启动类 |
| `entity/Product.java` | t_product 实体（BigDecimal 价格） |
| `mapper/ProductMapper.java` | CRUD + **@Update 乐观扣减库存**（stock>=quantity 防超卖） |
| `service/ProductService.java` | 接口：list/detail/getPrice/deductStock |
| `service/impl/ProductServiceImpl.java` | 实现：列表/详情（detail 带 **@SentinelResource** 流控）；getPrice、deductStock 为契约实现，失败返回业务码 4003 |
| ~~config/SentinelFlowRuleConfig.java~~ | 已删除：流控规则改由 **Nacos 数据源**统一管理（dataId: mall-product-flow-rules，见 application.yml + docker/nacos-config/） |
| `sentinel/ProductSentinelBlockHandler.java` | 详情接口被限流时的静态兜底方法（detailBlock） |
| `controller/ProductController.java` | 公开 /product/**；内部 /internal/product/**（契约实现） |
| `application.yml` | 端口 8082、mall_product 库、Nacos、Sentinel 控制台 + **flow Nacos 数据源** |

## 八、`mall-order/`
| 文件 | 说明 |
| --- | --- |
| `pom.xml` | common + nacos + **openfeign** + loadbalancer + **seata** + **sentinel + sentinel-datasource-nacos** + mybatis-plus |
| `OrderApplication.java` | 启动类：**@EnableFeignClients("com.mall.common.feign")** 启用公共契约 |
| `entity/Order.java` | t_order 实体 |
| `mapper/OrderMapper.java` | 订单 CRUD |
| `service/OrderService.java` | 接口：createOrder（全局事务入口）、detail |
| `service/impl/OrderServiceImpl.java` | 实现：**@GlobalTransactional** 查价(Feign)->扣库存(Feign)->建单；任一失败全局回滚；createOrder 带 **@SentinelResource**（限流 blockHandler + 异常 fallback） |
| ~~config/SentinelFlowRuleConfig.java~~ | 已删除：流控规则改由 **Nacos 数据源**统一管理（dataId: mall-order-flow-rules，见 application.yml + docker/nacos-config/） |
| `sentinel/OrderSentinelBlockHandler.java` | 下单限流/异常时的静态兜底（createOrderBlock / createOrderFallback） |
| `controller/OrderController.java` | 下单/详情；**userId 取自 X-User-Id 请求头**（网关注入，防越权） |
| `controller/SentinelDemoController.java` | 限流演示接口 GET /order/sentinel/demo（QPS=2），压测观察 429 blockHandler |
| `application.yml` | 端口 8083、mall_order 库、Nacos、Seata 客户端（tx-service-group=mall_tx_group）、Sentinel 控制台 + **flow Nacos 数据源** |

## 八.五、`k8s/`（Kubernetes 部署清单）
| 文件 | 说明 |
| --- | --- |
| `namespace.yaml` | mall-cloud 命名空间 |
| `configmap.yaml` | 共享环境变量（NACOS_ADDR / SENTINEL_DASHBOARD / OAP / 数据源公共项） |

| `infra-nacos.yaml` | Nacos Server 单机（8848/9848，PVC 持久化） |

| `infra-sentinel.yaml` | Sentinel 控制台（Service 名 mall-sentinel:8858） |
| `infra-skywalking.yaml` | SkyWalking OAP（Service 名 mall-oap:11800）+ UI |
| `app-gateway.yaml` | 网关 Deployment（2 副本）+ Service（唯一入口） |
| `app-user.yaml` / `app-product.yaml` / `app-order.yaml` | 三个业务服务 Deployment + Service（envFrom 注入共享配置 + 各自 DB URL） |
| `ingress.yaml` | nginx Ingress（host: mall.local -> 网关） |
| `README.md` | 镜像构建、部署步骤、验证命令、文件清单 |

## 八.七、`helm/`（Helm Chart 部署）
| 文件 | 说明 |
| --- | --- |
| `Chart.yaml` / `values.yaml` | Chart 元数据 + 全部可配置项（基础设施开关、四服务参数、密钥） |
| `files/` | 三库初始化 SQL（模板 `.Files.Get` 渲染进 init ConfigMap） |
| `templates/configmap.yaml` / `secret.yaml` | 共享环境变量（NACOS_ADDR/SENTINEL_DASHBOARD/OAP/DB/Redis）+ 敏感项 |
| `templates/mysql.yaml` 等 6 个 infra 模板 | MySQL(StatefulSet)/Redis/Nacos/Seata/Sentinel/SkyWalking，均可独立开关 |
| `templates/service.yaml` | **通用模板**：range 遍历 `values.services` 生成四个服务 Deployment + Service（dbName/extraEnv 表达差异） |
| `templates/ingress.yaml` / `NOTES.txt` | Ingress（唯一入口 -> 网关）+ 安装后提示 |
| `README.md` | 快速开始、参数表、复用外部基础设施、Sentinel 规则初始化 |
