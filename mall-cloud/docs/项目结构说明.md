# mall-cloud 项目结构说明（文件夹职责）

> 本文档说明**每个文件夹/模块**的职责。文件级说明见《文件说明.md》。

## 一、根目录

| 文件夹/文件 | 说明 |
| --- | --- |
| `pom.xml` | 父 POM：packaging=pom，聚合 5 个模块；用两个 BOM（spring-cloud、spring-cloud-alibaba）统一管理版本，内部模块版本统一 `${project.version}` |
| `README.md` | 项目总览：架构图、模块清单、快速开始、FAQ |
| `sql/` | 三个服务的**独立建库脚本**（独立数据库原则：服务间不共享表） |
| `docker/` | 基础设施编排：MySQL/Redis/Nacos/Seata/Sentinel 控制台；`skywalking/` 子目录（OAP+UI 编排与探针接入指南）；`nacos-config/` 子目录（**Sentinel 规则配置中心化**：规则 JSON + 发布脚本）；`service/Dockerfile` 微服务通用镜像（内置探针） |
| `k8s/` | Kubernetes 部署清单：基础设施（mysql/redis/nacos/seata/sentinel/skywalking）+ 4 个微服务 + Ingress |
| `helm/` | Helm Chart：基础设施 + 4 服务 + Ingress 一键部署（`k8s/` 清单的参数化收拢） |
| `docs/` | 本目录：结构说明 + 文件说明 |
| `mall-common/` 等 5 个模块目录 | 见下 |

## 二、模块目录

### 2.1 `mall-common/` — 公共模块（jar，无启动类）
| 子目录 | 说明 |
| --- | --- |
| `src/main/java/com/mall/common/` | 统一 Result、BusinessException、GlobalExceptionHandler（各服务扫 `com.mall` 包即生效） |
| `src/main/java/com/mall/common/feign/` | **Feign 服务间契约接口**（ProductClient/UserClient）。契约属消费方，定义在公共模块 = 依赖倒置，提供方实现、消费方继承 |

**为什么契约放公共模块**：mall-order 需要调用 mall-product，若直接 new 或复制接口，会形成强耦合；
契约放 common 后，消费方只需 `@EnableFeignClients("com.mall.common.feign")` 注入使用，替换实现不影响调用方。

### 2.2 `mall-gateway/` — 网关（Spring Cloud Gateway，WebFlux 响应式）
| 子目录 | 说明 |
| --- | --- |
| `java/.../filter/` | 全局过滤器：统一鉴权（白名单 + JWT 验签 + 注入 X-User-Id） |
| `java/.../config/GatewaySentinelConfig.java` | 网关限流兜底 429 JSON（**规则已配置中心化**：gw-flow/gw-api-group 由 Nacos 数据源拉取） |
| `resources/application.yml` | 路由规则（lb://服务名）、跨域、Nacos 注册、Sentinel 控制台 + Nacos 数据源（gw-flow/gw-api-group） |

**注意**：网关是 WebFlux 技术栈，**禁止引入 spring-boot-starter-web**，否则启动冲突。

### 2.3 `mall-user/` — 用户服务（独立数据库 mall_user）
| 子目录 | 说明 |
| --- | --- |
| `controller/` | 对外接口 + `/internal/**` 内部接口 |
| `service/` + `service/impl/` | 注册/登录（签发 JWT，密钥与网关一致）/ 内部查询 |
| `mapper/` `entity/` | 用户表 CRUD |

### 2.4 `mall-product/` — 商品服务（独立数据库 mall_product）
| 子目录 | 说明 |
| --- | --- |
| `controller/` | 商品浏览（公开）+ `/internal/product/**` 内部契约实现（查价、扣库存） |
| `sentinel/` | @SentinelResource 静态兜底方法；**流控规则已配置中心化**：由 Nacos 数据源拉取（`docker/nacos-config/mall-product-flow-rules.json`） |
| `mapper/ProductMapper.java` | **乐观扣减库存 SQL**（stock>=quantity） |

### 2.5 `mall-order/` — 订单服务（独立数据库 mall_order）
| 子目录 | 说明 |
| --- | --- |
| `controller/` | 下单/详情；userId 从网关注入的 `X-User-Id` 请求头取，不接收前端传参；`SentinelDemoController` 提供限流演示接口 |
| `sentinel/` | createOrder 的 blockHandler/fallback 静态兜底；**流控规则已配置中心化**：由 Nacos 数据源拉取（`docker/nacos-config/mall-order-flow-rules.json`） |
| `service/impl/OrderServiceImpl.java` | **@GlobalTransactional Seata 全局事务** + **@SentinelResource 限流**：Feign 查价 -> Feign 扣库存 -> 本地建单，跨两库强一致 |
| `resources/application.yml` | Seata 客户端配置（tx-service-group 与 seata-server 一致）+ Sentinel 控制台 |

## 三、`src/main/resources/` 通用约定
| 文件 | 说明 |
| --- | --- |
| `application.yml` | 各服务配置：端口、数据源（环境变量注入）、Nacos 注册/配置、MyBatis-Plus |
| （可选）Nacos 动态配置 | `spring.config.import: optional:nacos:服务名.yaml`，配置中心优先级高于本地 |

## 四、`sql/`、`docker/`、`docs/`
| 文件夹 | 说明 |
| --- | --- |
| `sql/mall_user.sql` 等 | 各服务建库建表 + **Seata undo_log 表**（AT 模式必需） |
| `docker/docker-compose.yml` | MySQL/Redis/Nacos/Seata/Sentinel 控制台 一键拉起；Nacos standalone 模式 |
| `docker/seata/` | seata-server 的 registry.conf（注册到 Nacos）+ file.conf（事务分组映射） |
| `docker/skywalking/` | SkyWalking OAP+UI 编排与探针接入指南 |
| `docker/service/Dockerfile` | 微服务通用镜像（内置探针，构建参数指定 jar 与服务名） |
| `docker/nacos-config/` | **Sentinel 规则配置中心化**：4 个规则 JSON + init-sentinel-rules 发布脚本 + 使用文档 |
| `k8s/` | K8s 部署清单：基础设施 + 4 微服务 + Ingress |
| `helm/` | Helm Chart：基础设施开关 + 4 服务参数 + Ingress 一键部署 |
| `docs/` | 结构说明 + 文件说明 |
